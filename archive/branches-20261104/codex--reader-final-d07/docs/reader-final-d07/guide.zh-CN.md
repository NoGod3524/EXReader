# EXReader 首版中文用户指南

适用范围：2026-10-25 固定实现起点的原生宿主。Windows、Linux GTK、Android、macOS、iPhone、iPad 的界面并不完全相同。本指南不代表六平台正式发行或互通验收。英文按钮保留原文，并附中文解释；没有出现的可选入口不要强行寻找。

## 开始阅读

<!-- source: G01 -->
**先取得正确构建。** 当前未在本指南认证可供普通用户下载安装的安装包、签名或商店发行。请向提供构建的维护者确认平台、版本与启用功能；不要把 Actions 的测试工件当成已发布安装器。本指南不提供虚构下载按钮。维护者可查[来源与构建状态](sources.md)。

<!-- source: G02 -->
**首次使用先保留一份原书，再导入一本小文件。** 不需要先连接云盘。启动后若显示初始化/书库错误，先按[故障恢复](#故障恢复)处理，不清空应用数据。

| 平台 | 导入、打开、翻页、返回 |
| --- | --- |
| Windows 正式基础界面 | 在“导入路径”填入本地文件路径，点“导入”；在书架选中书籍，点“打开”。使用“上一页”“下一页”。基础界面书架与阅读区同窗显示，不需要虚构一个返回按钮。 |
| Linux GTK | 点 `Import F1`（导入），在文件选择器选择书籍；从书架打开书籍，点 `Previous F3` / `Next F4`；`Shelf F2` 返回书架。 |
| Android | 点 `Import`（导入），在系统文件选择器选择文件；点书架条目打开，阅读栏翻页，点 `Shelf`（书架）返回。首次选择文件时允许系统授予该文件的读取权限，不需要交出整个云盘密码。 |
| macOS / iPhone / iPad | 点“打开文件…”，在系统选择器选书；点书名打开，使用“上一页”“下一页”，点“书架”返回。此为源码入口说明，移动 Apple 候选整轮失败尚未获得产品授予。 |

<!-- source: G03 -->
**继续阅读：** 再次打开同一本书，检查实际恢复的位置。已保存位置与最近一次尚未保存的操作不同；崩溃后不保证最后一帧也保存。只有 Windows compact 候选有明确“继续阅读”入口，不能据此要求其他平台出现同名按钮。字体或窗口大小变化会重新分页，页码变化不一定是丢进度。

## 导入书籍

<!-- source: G04 -->
导入格式接口涉及 EPUB、PDF、CBZ、TXT、HTML、FB2、DOCX、RTF、MOBI；文件扩展名不是成功保证，损坏、加密/不支持内容、过大或读取权限不足都可能失败。不要把文件选择器出现 `.azw3` 理解为所有 Kindle 书都可读。Android 正式宿主现有文档仍规定所有阅读输入 **32 MiB** 上限，独立暂存模块的 128 MiB 不等于宿主放宽限制。

<!-- source: G05 -->
| 来源 | 当前实际入口与边界 |
| --- | --- |
| 本地单文件 | 使用上一节各平台入口；Android 的系统选择器可多选，也接收系统分享/打开提供的 `content:` 文件。第三方 Provider 的真实兼容性仍需验证。 |
| 文件夹批量 | GTK 启用对应功能的构建：导入按钮旁 `▾` → `Import folder…` → `Choose folder`；仅需要子目录时勾选 `Include subfolders`。默认不是无限递归。其他平台不要把底层批量导入模块当作已经接入文件夹按钮。 |
| 拖放 / 剪贴板 | GTK 启用文件输入功能时可接收本地书籍文件拖放，`▾` → `Paste book files` 粘贴文件列表。不是粘贴书的正文、网页 URL 或任意远程路径。其他平台本指南没有认证同等文件拖放/粘贴入口。 |
| 云盘 / WebDAV | 系统文件选择器中的云盘位置由系统/Provider 提供，不等于 EXReader 有某品牌登录按钮。Windows 启用整理功能的 compact 菜单有“从云盘导入…”；选目录/书籍后“打开目录/导入选书”。账号书库的同步见下一节，不等于浏览任意云盘文件。 |
| 电脑连线 / 传书 | 本指南未确认 EXReader 内置 USB 传书、Wi-Fi 网页上传或常驻连线服务器。可先通过操作系统自己的文件传输把书放到设备，再从真实文件选择器导入；线缆、系统权限与第三方工具不在本指南验收范围。 |

<!-- source: G06 -->
**取消、重复与异常：** 选择器取消不应被当作导入成功。Android 复制时 `Import` 变为 `Cancel import`，SDK 工作阶段另有取消界面；GTK 批次取消只停止尚未提交的项目，已导入项目保留。批次报告中的失败、未执行、截断不等于全部完成。精确相同字节命中去重时不会再建一份书；不同版本或格式不是同一字节，不应靠重复导入解决版本冲突。损坏或空间不足时先保留原文件，阅读错误提示、释放与本应用无关的空间后再试；不要删除应用资料来“腾空间”。

## 书架与阅读

<!-- source: G07 -->
**找书：** 有产品书架功能的构建提供书名/作者搜索：Windows 书架搜索框、GTK `Search title or author`、Android 同名搜索框、Apple“搜索书名或作者”。书架按内部标题键稳定排序；本指南未确认六平台都有用户可选“最近阅读/作者/标题”排序菜单。清空搜索再刷新可排除只是被筛选隐藏。

<!-- source: G08 -->
**分类与整理：** GTK `More` → `Collections…`、Android `More` → `Organize` → `Kind` 下有 `Shelves`（子书架）、`Tags`（标签）、`Series`（系列）。进入子书架后按现有操作管理成员；Android 长按书籍可见 `Organize book`。`Removed` → `Restore` 是整理项目的恢复，不是恢复已经删除的所有书籍文件。Windows 的“批量整理…”为启用该功能的 compact 路径，可 Ctrl/Shift 选择 1–100 本，再“应用到选中书籍”；它与普通书架单选不同。Apple 本指南未确认对应分类/多选整理 UI。不能把从组中移除、移动子书架、删除书籍混为一谈。

<!-- source: G09 -->
**删除前：** Windows“删除”会删除本机书籍及其标注，不是单纯隐藏条目；GTK 顶栏 `Delete F10` 对应删除标注，**不是删书快捷键**。删除书架记录、移除分组成员、删除应用持有的本机副本，与删除你另存的外部原件不同。保留外部原件，不依赖回收站或重新导入来恢复标注。云端墓碑与本机副本也不是自动同步物理删除。本指南没有确认通用“撤销删书/恢复全部原件”按钮。

<!-- source: G10 -->
| 操作 | Windows | GTK 可选功能 | Android 可选功能 | Apple |
| --- | --- | --- | --- | --- |
| 书内搜索 | “书内查找”→“查找”→“定位” | `Search within book…` | “书内搜索”→“搜索” | “查找” |
| 目录/跳转 | “目录” | `More` → `Directory / page entries…` | “目录 / 按页入口” | “目录” |
| 进度/书签 | “阅读记录” | `Reading records…` | “阅读记录”→“保存进度”“添加书签” | 更多阅读操作→“阅读记录”→“保存阅读进度”“添加书签” |
| 标注 | “全选本页”“添加标注”“跳转标注” | `Text F7`、`Add note F8`、`Notes F9` | `Select` / `Notes`，或阅读记录“标注选中文本” | “选文”“标注”；选文界面“标注所选” |
| 字体/缩放/主题 | “字号-”“字号+”“缩放-”“缩放+”；设置需对应构建 | `A+ F5` / `A− F6`；设置为可选功能 | “阅读设置”：字号、行距、页边距、固定页缩放；“深色（暂不可用）”不能视为可用深色 | “A-”“A+”；更多阅读操作中的“阅读主题”须启用该功能 |

<!-- source: G11 -->
**固定页差异：** PDF/CBZ 的页面缩放不等于重排字体；没有作者目录时，“按页入口”不是自动生成作者大纲。扫描图像没有可搜索文字时，不能承诺 OCR、选文或全文搜索。出现“定位失败”请保留记录，核对原书版本；不要通过删记录掩盖失败。阅读记录中的恢复版本需要原书位置核验，不代表任意冲突自动合并。

## 自有 WebDAV

<!-- source: G12 -->
**准备：** 使用你有权访问的 HTTPS 文件夹地址（以 `/` 结尾），以及服务提供方认可的账号/密码或应用专用密码。地址中不要塞密码、令牌或查询参数。同一书库已绑定其他账号/地址时，不要强改资料绕过绑定。不同账号书库可能相互隔离，切换账号不保证看到原本本地书架。

<!-- source: G13 -->
| 平台 | 设置与首次同步（入口需在构建中启用） |
| --- | --- |
| Windows | “账号”→“账号与同步”，填“服务器地址”“用户名”“密码”，选择是否“保存到系统安全存储（取消勾选则仅本次会话）”，点“应用”，再“立即同步”。失败/取消后可用的“重试”从成功位置继续；“忘记凭据”不是删除书库。 |
| GTK | `More` → `Account / Sync…`，填写地址与凭据；默认 `Only for this app session`（仅本次会话），需要时选 `Remember in system secure storage`；`Apply credentials`（应用凭据），`Sync library`（同步书库），需要接收原书时 `Receive books`。`Retry`、`Cancel`、`Disconnect` 各有独立含义，断开不等于删书。系统安全存储不可用时不要假定凭据已经永久保存。 |
| Android | `More` → “同步”→“云盘账号”，选择“安全保存”或“仅本次使用”；回同步界面点“立即同步”，用“刷新书目”查看，点可接收书籍→“接收”。“移除凭据”保留书籍和书库绑定。 |
| Apple | “本地书库/云盘书库”→“连接 WebDAV”，填地址、用户名、“密码或应用专用密码”；按需勾选“保存到钥匙串”→“连接”。在该书库点“同步”；更新密码走“更新授权”→“保存授权”，不是新建另一地址的书库。 |

<!-- source: G14 -->
**离线与重连：** 已经下载且能打开的本机书可以离线阅读；只有远端书目不代表原件在本机。恢复网络后手动同步，等待状态与接收结果；本产品没有在本指南获证的后台实时协作服务。关闭同步界面、取消与退出的行为有平台差异，以状态提示为准；重开后先确认当前账号、凭据是否仍在，再同步。仅本次使用的凭据可能需要重新输入。

<!-- source: G15 -->
**冲突：** 同步状态出现并发版本、待依赖、受限、墓碑或“需要先解决冲突或恢复”，先保留本机原书和记录，查看所涉及书目/阅读记录的版本信息。GTK 书架冲突区域可打开 `Book versions` 提示（不是解决器）；Apple 阅读记录有“选择恢复版本”，确认原书核验通过才执行；这不等于全库冲突解决器。其他不能明确选择的冲突先停止反复写入，向维护者提供去敏错误与操作经过。没有通用“自动合并所有冲突”按钮；不承诺端到端加密、实时协同、六平台全量双向互通或隐藏服务器。

## 故障恢复

<!-- source: G16 -->
处理前统一遵循：保留外部原书和本地应用资料，不卸载、不清数据、不直接编辑 SQLite/JSON。若需要资料副本，请由维护者说明适合当前平台的离线备份方法；本指南不虚构应用“备份/导出全部”按钮。

| 可观察症状 | 先做什么 | 仍未解决时 |
| --- | --- | --- |
| 导入失败/停在复制 | 看错误是否为权限、格式、大小、空间；确认原文件可读取；使用真实取消按钮等任务结束后再试一份小文件。批量导入先看逐项结果。 | Android 进程退出前未完成 URI 复制需要重新选择/分享文件；已发布私有字节才可能恢复。不要反复提交同一失效授权。 |
| 有书目但打不开 | 确认原书已接收而不是仅看到远端目录；检查是否选错账号与书籍版本。 | 保留错误文字；不要删书重导来尝试“修复标注”。 |
| 书架缺书/信息待恢复 | 清空搜索；有 `Refresh`/“刷新”时使用它；Apple 显示“产品索引待修复”时按提示重启后重试。 | 已保存原书不等于产品索引已修复；不要把最多 50 本兼容列表当作所有书丢失。 |
| 记录定位失败 | 保留记录，核对原书版本/格式，从目录或手动翻页回到位置。 | 记录错误及操作，不编辑锚点、不强选不明恢复版本。 |
| 认证失败/网络失败 | 检查 HTTPS 地址、网络与账号权限；通过原有账号设置更新凭据。Windows/GTK 有“重试”时使用；Android/Apple 重新手动同步。 | 记录状态码和时间；绑定错误不能靠换 URL 或直接改数据库解决。 |
| 出现冲突 | 查看同步状态和记录版本，不重复覆盖或删除。 | 没有相应版本处理入口时交给维护者，不假定重新同步会自动解决。 |
| 应用意外关闭 | 重新启动，确认账号与书架，再打开同一本书核对位置；等待已提交资料恢复。 | 未完成导入可能需要重选文件；无备份/导出入口时保持资料原状等待诊断。 |

<!-- source: G17 -->
**反馈时提供：** 平台/系统版本、构建版本、书籍格式和大致大小、出现问题的按钮、去敏错误、发生时间、是否离线及是否重启。不要发送密码、Authorization、令牌、含密钥 URL、私人书籍全文或整份私有数据库。截图请遮盖私人书名和账号；本指南未使用任何模拟 UI 图。
