# 独立云端CPU测量候选

现有SDK预算固定于AMD EPYC 7763，生产门禁与预算保持不变。
PR5的两次性能作业分别分配到EPYC 9V45与9V74，均在采样前被环境守卫拒绝；
云端原件诊断确认编译器和参考工具相同。

本分支只增加独立候选工作流。三份测量各自运行原来的八文档、40个原生进程和12个参考进程，
使用原始contract、字体、SDK保护树和原件身份；不传预算参数，执行已有baseline-only路径。
每份报告分别登记实际CPU、编译器和参考工具，不能合并不同环境或run的数据。

即使测量完整，`accepted=false`、`review_required=true`；不授予PR、SDK或产品验收。
新CPU预算与允许环境必须另行明确评审，不能替代、归一化或放宽旧CPU及旧预算。
此分支不合入产品PR，不创建tag或Release。所有执行和工件处理只在GitHub Actions。
