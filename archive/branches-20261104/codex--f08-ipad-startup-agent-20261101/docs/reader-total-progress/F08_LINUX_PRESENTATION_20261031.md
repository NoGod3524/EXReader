# Linux direct presentation capability

This diagnostic starts from 0c89ee0bee126c2316b2a6445bde7a5a47bb42f3, which contains the measured catalog WAL repair. It changes five test/documentation files and no product tree. Both CI jobs have a 20-minute bound. The isolated Xvfb remains 1440x900x24; this does not change the user's desktop resolution.

GTK 3.24.33's Wayland `fill_presentation_time_from_frame_time` estimates presentation from the frame callback and refresh period. A nonzero GTK field therefore does not establish native presentation completion. This probe requests `wp_presentation.feedback` directly for each of 120 changing GTK surface submissions. It retains the native timestamp, clock domain, refresh, output count, sequence and reliability flags, plus the measured request and callback-arrival times. Presented, discarded and pending submissions all remain in the census. Timestamp zero is retained as unavailable.

The native protocol binds feedback to the next `wl_surface.commit`; it describes the presentation timestamp as final realized presentation time. Its hardware flags describe timestamp provenance and quality. They are reported, not added as new F08 requirements. Mutter 42.9 forwards `ClutterFrameInfo.presentation_time` and unconditionally sets HW_COMPLETION, so that flag alone cannot prove hardware measurement. Native feedback must still be traced to the actual backend before it can replace the missing product timing evidence.

This synthetic capability does not execute EXReader, does not define product framecost, and cannot satisfy the P95/P99 budgets. Request-to-callback time includes protocol delivery and main-loop scheduling; it is not CPU render time. A successful artifact audit authenticates the diagnostic only. Original 2202-book evidence and every existing failure remain intact. F08 stays pending.

Sources: [GTK 3.24.33 Wayland timing](https://github.com/GNOME/gtk/blob/3.24.33/gdk/wayland/gdkwindow-wayland.c#L492), [presentation-time protocol](https://gitlab.freedesktop.org/wayland/wayland-protocols/-/blob/main/stable/presentation-time/presentation-time.xml), [Mutter 42.9 feedback implementation](https://github.com/GNOME/mutter/blob/42.9/src/wayland/meta-wayland-presentation-time.c#L276).
