## 需要引擎提供的语义

允许按单元格段落 ID 向零 run 段落插入 TEXT run，保留段落 ID、模板、
属性以及同格其他段落；参与事务、rollback、undo/redo，写回重开后可继续编辑。
可扩展现有 API 或新增段落内插 run API；不要以整格替换实现。

已有 set_run_text 只能修改现存 TEXT run；insert_paragraph 的锚点只接受
顶层块；set_cell_text 会替换整格为一段。这三个公开入口都不能直接完成上述语义。
复现检查了失败回滚及整格替换回滚，DOCX 字节和原段落 ID 均保持不变。
无 UI 实现，因此合并格导航、绘制、工具条行为尚未验证。
