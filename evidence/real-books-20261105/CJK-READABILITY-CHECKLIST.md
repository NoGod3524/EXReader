# 中文可读性最小清单 · 独立验收

本清单用于第3步完成后的独立中文可读性验收，不将全部项目塞入第3步或2a。当前仅有日文《草枕》的CJK视觉证据；原15本语料没有中文样本。**中文行宽仍缺验证；补齐需另行提供中文书。**

“每行28–34汉字”这个口径，当前样本验证只限日文《草枕》，不能据此记为中文已通过。该数值是后续中文行宽/容量目标，不要求段末或章末短行凑满，也不宣称现有日文图片每行均已数到28–34字。

| 项 | 最小验收口径 | 记录方式与当前状态 |
| --- | --- | --- |
| 1. 段首缩进 | 检查普通段落及对话/续段/标题例外；作者未指定时，宿主提供可配置的CJK默认2em，尊重作者显式声明和用户覆盖选择 | 记录适用CSS、缩进em值及段首坐标；设置归第5步。当前日文普通段声明1em，中文缺省场景待验 |
| 2. 行宽/每行容量 | 在固定字体、字号、视口下，以28–34个全宽汉字作为正文行宽容量目标；区分横排“行”和竖排“列”的行进轴；章末短行不算不足28字的失败 | 保存参数、正文行/列计数与离屏图；当前只有日文样本对照，中文未验证。宿主区域约束归第3步 |
| 3. 行高与段间 | 正文、ruby/注音、段间在采用的行高下不碰撞、遮挡；调整字号/行高后没有裁字或异常空页 | 记录实际字号、行高、字形边界及离屏图；中文待验，不以日文已观察结果替代 |
| 4. 中文标点空白/挤压 | 逗号、句号、顿号、引号、括号前后不出现异常大空洞或重叠；挤压后标点与正文的相对位置仍正确 | 按标点类别记录坐标/间距及局部离屏图；中文待验，日文标点行为不能直接外推 |
| 5. 避头尾 | 行/列首不悬挂禁止起首的闭标点，行/列尾不孤立留下开括号/开引号；同时观察破折号、省略号等连续标点的跨行处理 | 记录发生位置、前后行/列边界与离屏图；中文待验，不因本轮日文竖排成功而关闭 |

语言、字体、字号、视口与书内CSS必须随结果一起记录。拉丁文字的字符/行统计和未启用断词的右缘表现，不可充当上述中文验收结果。

本轮只落盘清单；不提供新的中文商业书、不构造样本替代真书配额、不修改产品代码或排版参数。
