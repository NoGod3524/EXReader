## 1. 两个合成命中点的条件谓词与 30 页覆盖统计

p71–100（30 页，@1200，`1200×900`，共 32,400,000 目标像素）每页内容流结构一致：先整页实色填充底色 `(242, 245, 250, 255)`，再依次绘制 3 张 8×8 平坦分块双线性图像（90 次 `axis_paint`，全部 `flat=1`，且每张图像均带矩形裁切 `re W/W* n`；由于 `1200/720 = 5/3` 非整数像素对齐，裁切掩码在每行左右边缘 1 像素为半透明覆盖，内部全为 `255`）：

- `ImBg`（945,756 像素/页）：12 页无 SMask（全不透明，`op12`），18 页带同尺寸最近邻灰度 SMask（alpha ∈ ~75–190，`mk18`）。
- `ImTile1`（184,368 像素/页，内区 182,634 像素）：30 页均无 SMask（全不透明），叠加在 `ImBg` 上。
- `ImTile2`（184,368 像素/页）：30 页均带最近邻灰度 SMask（alpha ∈ ~75–190），叠加在 `ImBg` 上。

对应前序归因（`EXREADER-IMAGE-P71-P100-SPLIT.md`）的两个命中点，全部 39,419,730 次像素写入均落在 `src/affine_image.c` 的 `axis_paint` 内（`target->channels == 4` 恒成立）：

### Bit-exact 数学证明

1. **不透明直写（P3a / P4a）**：在 `target->channels == 4`、`(color & 255) == 255`、`coverage == 255` 时，`exr_pixel` 计算 `alpha = 255 * 255 / 255 = 255`：
   - `p[3] == 255`：`(p[k]*0 + c*255 + 127)/255 = c`，`p[3]` 保持 `255`；
   - `p[3] == 0`：直接写 `p[0..2]=c`、`p[3]=255`；
   - `0 < p[3] < 255`：`denominator = 255*255 + p[3]*0 = 65025`，`(c*65025 + 0 + 32512)/65025 = c`，`(65025 + 127)/255 = 255`。
   三分支输出完全一致，均与目标原值无关，等价于直接写 `{r, g, b, 255}`。
2. **平坦半透明同底跳过（P4b）**：在 `axis_flat_row_paint` 的一个 run `[start, end)` 内且 `[start, end) ⊆ [full_x0, full_x1)` 时，`target->channels == 4`、`rgba`、`coverage == 255` 均为常量。查看 `src/pixels_internal.h` 中 `exr_pixel`，输出 4 字节是 4 字节输入 `dst` 的纯确定性函数 `f(rgba, dst)`，无其它读写状态。对 run 首像素（及后续每次 `cur != last_dst`）直接调用原版 `exr_pixel(target, k, y, rgba, 255)` 并记录 `(last_dst, last_out)`，随后对所有 `cur == last_dst` 的像素（含 SSE2 4 像素 `pcmpeqd` 命中）写 `last_out`，在所有目标 alpha（0 / 1..254 / 255）下均严格逐比特等价。
3. **零 alpha 跳过（P_zero）**：`(color & 255) == 0` 时对任意 `coverage ∈ [0,255]` 有 `alpha = 0`，`exr_pixel` 直接返回。

**消融结论（每项贡献清晰可加）：**
1. **P4a（Site 4 不透明直写）**：在 `op12` 12 页上直接带来 **~+8.8%（~+45 ms）**；单开时在 `mk18` 上略损 −1.6%（两遍扫描未跳过半透明 run）。

## 5. 代码改动与复现说明

- **生产代码**：`src/affine_image.c`
  - `axis_clip_full_span`：每行以 SSE2 16 字节步进识别裁切行内唯一连续 `cov == 255` 区间 `[full_x0, full_x1)`（非凸带空洞裁切安全回退为空区间）。
