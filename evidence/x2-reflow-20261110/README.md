每场景 31 个独立 100 页模型，1,000 个段落。页配置为 400×232、边距 16、字号 16、行高 1.25、段间距 0；字体 tests/fixtures/fonts/primary.ttf。测试为 Windows x64 / GCC Release。p50/p95 使用排序后的第 16/30 个样本。重排计时包含快照比较、脏区推导、修改段落 shaping、行重分页和缓存失效；X1 修改命令本身在计时外。完整重建为同一修订重新创建整个编辑 pager。

“冷缓存首帧”强制清空页负载 LRU 后，读取首个脏页并执行 exr_render_page_color，包含位图释放；原有段落行几何仍保留。表中组合耗时按每轮的重排与首帧耗时相加后取分位数。四场景重排及组合 p95 均低于 16ms。宿主翻页 p95 14.53ms 是用户提供的参照，不是同一负载的对照样本。

X1 尚没有替换文字命令；第三场景通过 exr_edit_doc_create 提交保留全部块/运行 ID 的修订快照，只把末尾“.”改成“!”。插入、批量事务、删除、拆段、属性修改、撤销/重做均直接调用 X1。此实现不修改 X1 文件。长单段跨几十页修改最后一字也断言只重排 1 页。

缓存探针固定读取旧页 0、10、49、50、98、99，容量 64 页，字节预算 8 MiB。每轮先预热这六页，重排后再读同样六页；下表不混入后续冷首帧强制失效产生的计数。原页满载时，末尾追加不失效任何旧页。

除上述命中数外，convergence 用例保留硬分页之后的同一缓存对象：页号从 8 变为 9，源字节位置随插入调整，字形几何不变。所有增量结果逐页与完整重建比较源范围、字形、行几何，并在首/中/末页比较完整 RGBA 像素。
