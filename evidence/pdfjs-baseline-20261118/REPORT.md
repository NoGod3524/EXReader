# PDF.js 实测基线（本机，2026-11-18）

## 为什么需要这份文件

项目此前一直用「PDF.js 首屏 13 ms / 翻页 4 ms」作对照，**那两个数字从未在本机验证过**。
2026-11-18 本机实测后，两者都不成立。本文件固化真实基线，避免再次引用错误对照。

## 测量方法

```
Node v24.19.0
pdfjs-dist@3.11.174 + node-canvas
  另注：v4 + node-canvas 在含图像页面报 "Image or Canvas expected"
        v4 + @napi-rs/canvas 原生崩溃（exit -1073741819）
计时窗口：只包 page.render()，与本引擎的 exr_fixed_render 同口径
每夹具：1 轮预热 + 5 轮测量；空载 CPU 9–14%
机器：Intel Core Ultra 7 256V（8C/8T）、Windows 11 build 26200
```

复现脚本见 `bench.mjs`。

## 归因（这一轮真正的收益来自哪里）

| 收益 | 来源 | 性质 |
| --- | ---: | --- |
| deck −44%（终段） | 跨扫描行复用 clip 覆盖（#245） | **避免重复工作** |
| pptx@600 −39% | 字体流跨页保留（#244） | **避免重复工作** |
| deck −61%（中段） | 去掉 Matte 图像的缓存 bypass（#239） | **避免重复工作** |
| deck −55% | 纯色图 + 不透明遮罩预计算列索引（#243） | 避免重复计算 |
| SIMD 混合内核 4.43× | 端到端 0–5%（噪声内） | 算术加速 —— **不是瓶颈** |

**结论：瓶颈不是「每像素算得更快」，而是「同一件事被重复做了几遍」。**
