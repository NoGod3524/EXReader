# A1 搜索倒排索引验收

完整结果与线性搜索 **20/20 一致**；“的”和“寶玉”三轮冷/热首批 64 条均 **≤50 ms**；索引内存 **2.8283%**；ctest **248/248**；19 本真书逐页哈希零变化。

## 索引结构与调用

正文按 part 写入磁盘快照，按文档顺序切块，块内按 `(token, offset)` 排序形成完整位置表。CJK 按字，拉丁按小写词哈希，同时保留标量位置表以支持原有子串语义。CJK 多字查询做位置交集，其余候选回查原文；块边界和重叠命中均保留。结果是原文 UTF-8 字节范围，可直接创建锚点。

新增 build/search/info/save/load 五个 publication API；首次搜索按需建 part，游标和结果上限支持分批续读，回调即时推送命中，build 可按 part 在宿主工作线程续建。缓存包含版本、源内容身份、目录身份、校验和及结构检查；完整缓存重开不调用正文 loader。没有修改旧搜索签名/实现或 PDF 搜索头文件。用法见 [SEARCH_INDEX.md](../../docs/SEARCH_INDEX.md)。
