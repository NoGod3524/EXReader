# Windows 阅读设置（F3）：原生设置窗口与页面主题

Windows 正式宿主（`apps/reader/windows-account`）新增一个默认关闭的可选构建项
`EXR_READER_WINDOWS_PREFERENCES`，打开后得到唯一的原生入口「设置 → 阅读设置…」（Ctrl+,）。
所有低频选项都在这个窗口里，主界面不新增常驻工具条按钮。

## 入口与界面

- 一个原生菜单项，一个窗口。窗口内分两段：常用项（字号、行距、段落间距、页边距、主题、
  翻页方向、翻页操作、固定页缩放）与可折叠的「配色」段（浅色文字/背景、深色文字/背景）。
- 文案为中文，不出现 SDK、协议或调试术语。
- 「应用」是唯一的落盘动作；「默认值」只填入公开 F3 默认值，仍需「应用」。
- 「导入旧设置」把 `host.ini` 里的旧字号百分比与缩放比例显式读入（只读用户点过的那一项），
  填入窗口后仍需「应用」。
- 设置文件损坏或版本不受支持时，窗口提示原文未改动，普通「应用」不会覆盖它；只有
  「重建默认设置」会用公开默认值重写该文件。

## 渲染

- 重排书籍（TXT/EPUB）用 3.41.0 新增的 `exr_render_page_background` 直接生成页面画布：底色由
  所选主题决定，正文、图片、边框、彩色字体按原顺序绘制。不是先画白底再整体染色，也不做
  截图像素修改。
- 前景色通过公开的用户样式表（`exr_layout_config.user_css`）在既有排版路径里生效，随
  pager 创建时整体复制，不修改书籍源文件、不动 `document_css`、不加内联样式。
- 固定页书籍（PDF/CBZ）保持原书内容与颜色：`exr_fixed_render` 仍以不透明白底出图，
  主题只影响窗口界面；固定页缩放走同一个真实渲染器。
- 未被显式选择过设置时（没有 `preferences.json`），宿主走原来的渲染入口，
  与关闭该选项的构建逐像素一致。

## 存储

- 设备本地文件：`<数据目录>preferences.json`（`--data` 指定的账户目录内，UTF-16 路径
  转 UTF-8 后交给已安装的 `EXReaderPreferences`）。
- 读写只用该包的严格原子 API：校验 → 同目录临时文件 → 刷盘 → 原子替换。
- 保存失败（磁盘拒绝、占用、路径错误）时窗口报错，已接受的画面与设置都不变；旧文件保持完整。
- 未知版本、损坏或不合法文件不会被静默覆盖；重建必须由用户显式触发。

## 一线程与作业

- 界面线程只做窗口、采样系统外观和提交作业；SDK 的排版、渲染和落盘都在既有的唯一 worker 上。
- 一次设置选择就是一个作业：排版/渲染成功后先严格保存，保存成功才发布新画面与设置记录；
  任一步失败或取消都保留已接受的画面与设置。
- 系统深浅色只在界面线程采样（`WM_SETTINGCHANGE`/`WM_THEMECHANGED`），作为不可变值随作业下发；
  worker 不读界面可变状态。忙碌时只保留最后一次通知，完成后合并成一次重绘。

## 翻页

- 「翻页操作」决定点按、滑动、点按和滑动、硬件按键四种方式；「翻页方向」决定左右/竖排与
  从右到左的反转。
- 硬件按键模式下方向键/翻页键按所选方向翻页；输入法组合键（`VK_PROCESSKEY`）不翻页。
- 连按仍走既有调度：同一时刻只有一个运行中的作业和一个待执行作业。

## 验证入口

- 工作流 `.github/workflows/reader-windows-preferences-ui.yml`：完整复用现有
  Windows 导入/整理生产流程（J01 47、J10 21、F1 264、F2 130、导航 UI 31、记录 32、UI 158、
  账户/书架/元数据/worker/无障碍全部原样），再额外构建 3.41.0 候选 SDK 与打开 F3 选项的宿主。
- 新测试在 `tests/reader_windows_preferences/`：真实 SendInput/UI Automation/原生控件驱动，
  独立截取当前窗口像素，独立读取保存后的公开 F3 文档与 SQLite，真实重启后复验。
- 期望值与拒绝条件见 `docs/validation/reader-windows-preferences.json`。

## 如实说明的范围

- 本分支是独立候选：SDK 3.41.0 与 F3 窗口只在本分支验证，未推入冻结的公共分支。
- 原生 UI 通过不等于设备、性能或读屏验收；固定页缩放在宿主 4096 像素上限处会明确拒绝，
  不会静默降级。
- `custom-font-library`（D02） 不在本包内；字体仍用既有 `Reader.otf`/`--font` 机制。
