# EXReader Windows 线框（2026-11-04）

本轮未改任何代码，未触碰 `examples/` 与受保护树。

- 参考客户区：**1280×800 DIP**，96 DPI。所有数字单位是 DIP。
- 线框是示意，**坐标表是规范**，以表为准。`[x1..x2, y1..y2]` 为左闭右开。
- 令牌见 [UI-SPEC-20261104.md](UI-SPEC-20261104.md)，行为见 [INTERACTION-20261104.md](INTERACTION-20261104.md)。

规则：

- 改动立即生效并保存，没有“应用”和“取消”。主题、方式、方向、缩放立即重绘；字号、行距、段距、每行字数防抖 150 ms 后重排。
- 正文不因面板移动，面板盖住的部分照常更新。
- 客户区高 < 720 时，面板内容滚动，滚动条 8 宽贴右边。
- `reader_preferences` 的 `font_size` 现在是 720×1040 页面上的点数。改成 DIP 语义后旧值不能直接沿用，迁移方式在实现阶段确定；现有书架和进度不受影响。
- 书架上打开时结构相同，面板同样位于 `[920..1280, 48..800]`。
- 最小窗口 720 宽时面板坐标为 `[360..720]`，内容列不变。
