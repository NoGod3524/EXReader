# EXReader Windows 交互模型（2026-11-04）

> 2026-11-10 更新：旧 17 控件界面已移除，包含其布局、101–117 消息入口及返回旧面板路径。下文涉及旧控件、phase-a/b/c、旧无障碍证据与 `--debug-ui` 的描述仅为历史；[归档及清单](archive/legacy-17-control/README.md)。当前产品仅使用新界面。

本轮未改任何代码，未触碰 `examples/` 与受保护树。令牌见 [UI-SPEC-20261104.md](UI-SPEC-20261104.md)，尺寸见 [WIREFRAMES-20261104.md](WIREFRAMES-20261104.md)。

## 1. 屏幕与路由

| 屏幕 | 进入 | 离开 |
| --- | --- | --- |
| 书架 | 启动时没有上次在读的书；阅读页按 Alt+← 或点左栏“书架” | 打开一本书 |
| 阅读页 | 启动时恢复上次在读的书（沿用现状，`reader.c:6347`）；双击书卡、Enter | Alt+←、左栏“书架” |
| 目录 / 标注 | 阅读页内的左栏面板 | 再点“目录”、Ctrl+G、Esc |
| 设置 | 顶栏“设置”、Ctrl+,，书架和阅读页都可打开 | 再点“设置”、Ctrl+,、Esc、点面板外 |

离开阅读页时保存进度，沿用现有路径。上次的书已被删除或打不开时，回到书架并按 §7 报错。

## 2. 阅读优先布局

- **顶栏只留：书名、目录、设置。** 书架上书名位置显示“书架”，目录隐藏。
- **左栏三态**：展开（书架 200，阅读 280）/ 收窄（48，只有图标）/ 隐藏（全屏）。Ctrl+B 切换展开和收窄。
  - 书架默认展开；阅读页默认收窄。
  - 客户区宽度 < 960 时书架左栏自动收窄。
- **正文限宽居中**：版心 `clamp(28em, 34em, 可用宽 − 96)`（默认窗口下恒为 34em，34 汉字，2026-11-05 改，原 32em），在左栏之外的区域水平居中。
- **重排规则**：
  - 只有 `page.width_px`、`page.height_px`、字号、行距、段距、DPI 变化才重排。
  - 窗口变宽、开合左栏只重新居中，**不重排**，因为版心宽度没变。
  - 窗口变高会改变 `page.height_px`，同样重排。
  - 拖动窗口时防抖 150 ms；重排前先用上一帧按新位置贴图，不拉伸。
  - 重排后落回同一内容锚点。
- **窗口放不下版心时**：
  - 可用宽度 < 版心 + 96 时，版心 = 可用宽度 − 96，每行字数被动减少，文字到窗口边缘始终 ≥ 48。
  - 打开目录面板放不下时，面板改为浮层盖住正文，不触发重排；点面板外关闭。
- **固定页（PDF/CBZ）**：`exr_fixed_render` 的 scale 按“适应页面 × 缩放 × DPI/96”直接计算，位图 1:1 显示。放大后滚轮和方向键平移，到页边再翻页。
- **全屏（F11）**：隐藏顶栏、左栏、页码（2026-11-05 起状态行取消，页码在正文区底部）；鼠标移到屏幕顶端 8 DIP 时临时显示顶栏。

## 3. 鼠标

| 位置 | 操作 | 结果 |
| --- | --- | --- |
| 正文区左 30% | 单击（位移 ≤ 6 DIP） | 上一页 |
| 正文区右 30% | 单击（位移 ≤ 6 DIP） | 下一页 |
| 正文区任意处 | 拖动（位移 > 6 DIP） | 选择文字 |
| 正文区 | 滚轮 | 累计满 1 格（120）翻 1 页；固定页放大时平移 |
| 正文区 | Ctrl+滚轮 | 流式书调字号，固定页调缩放 |
| 书卡 | 单击 / 双击 | 选中 / 打开 |
| 窗口 | 拖入一个书籍文件 | 导入后打开（新增，交付包现无拖放） |

设置中的翻页方向（从左到右、从右到左、纵向）和输入方式（点击、滑动、两者）沿用 `reader_preferences` 的语义。

## 4. 导入

- 只用系统文件对话框（`GetOpenFileNameW`），一次一个文件，不提供路径输入框。批量导入不在本次范围。
- 入口：左栏“导入”、空书架按钮、Ctrl+O、拖入窗口。
- 过滤器沿用现有列表：`*.epub;*.pdf;*.cbz;*.txt;*.fb2;*.html;*.docx;*.rtf;*.mobi;*.azw3`。
- 对话框取消：什么都不发生，不显示提示。
- 手打路径只在 `--debug-ui` 保留。

## 5. 键盘映射

判定顺序沿用 `apps/reader/keyboard-actions`：输入法组合中的按键一律不触发；焦点在输入框时只响应带 Ctrl 的组合；焦点在按钮或列表时 Space 和 Enter 属于该控件。

“不变”指与带功能宏的构建一致。交付包目前只有 ←、→、PgUp、PgDn、Home、Ctrl+A、Ctrl+C、Ctrl+O、Ctrl+I、Esc，其余对它都是新增。

### 阅读页

| 操作 | 按键 | 与现状的差异 |
| --- | --- | --- |
| 下一页 | →、PgDn、Space、↓ | 新增 Space；↓ 现状仅设置激活时有效 |
| 上一页 | ←、PgUp、Shift+Space、↑ | 新增 Shift+Space |
| 本章首页 / 末页 | Home / End | End 新增 |
| 上一章 / 下一章 | Ctrl+← / Ctrl+→ | 新增；无章节结构时页码位置提示“这本书没有章节” |
| 搜索 | Ctrl+F | 不变 |
| 目录 | Ctrl+G | 不变 |
| 字号或缩放 增大 / 减小 / 复位 | Ctrl+= / Ctrl+- / Ctrl+0 | 新增；流式书改字号，固定页改缩放 |
| 全屏 | F11 | 新增 |
| 设置 | Ctrl+, | 不变 |
| 左栏展开或收窄 | Ctrl+B | 新增 |
| 全选本页 | Ctrl+A | 不变 |
| 复制引用 | Ctrl+C | 不变 |
| 添加标注 | Ctrl+M | 新增，需要已有选区 |
| 书签与阅读记录 | Ctrl+L | 不变 |
| 位置后退 / 前进 | Ctrl+[ / Ctrl+] | 不变 |
| 回书架 | Alt+←、BrowserBack | 不变 |
| 上下文菜单 | Shift+F10、Apps 键 | 新增 |

**Esc 逐层退出**，每按一次只退一层：取消慢任务 → 关闭菜单或面板 → 清除选区 → 退出全屏。书架上 Esc 清空搜索框。Esc 不回书架。

### 书架

| 操作 | 按键 |
| --- | --- |
| 移动选中 | 方向键 |
| 打开 | Enter |
| 导入 | Ctrl+O |
| 搜索框 | Ctrl+F |
| 删除（确认后） | Del |
| 详情 | Alt+Enter |
| 设置 | Ctrl+, |
| 同步账号 | Ctrl+Shift+A |
| 云盘导入 / 批量整理 | Ctrl+Shift+I / Ctrl+Shift+O |

**行为变更**：现状页面内 Ctrl+O 是“打开所选书”，Ctrl+I 是“导入”（`reader.c` 的 `page_procedure`）。新模型 Ctrl+O 统一为导入。`--drive` 脚本不走快捷键，不受影响。

Tab 顺序：顶栏 → 左栏 → 内容区（页码不可聚焦）。阅读页打开后焦点在正文。

## 6. 右键菜单

| 位置 | 菜单项 |
| --- | --- |
| 书卡 | 打开 · 详情 · 收藏或取消收藏 · 从云盘导入 · 批量整理 · 导出原件 · 删除 |
| 正文，无选区 | 全选本页 · 复制引用（有所选标注时） · 目录 · 设置 |
| 正文，有选区 | 复制引用 · 添加标注 · 清除选择 |

带功能宏才有的项，在对应能力未编译时不显示。

## 7. 空状态与错误态文案

文案中的尖括号是变量。“位置”指显示方式，尺寸见线框。

### 空状态

| 状态 | 触发 | 标题 | 说明 | 动作 |
| --- | --- | --- | --- | --- |
| 空书架 | 书架 0 本 | 书架还是空的 | 导入一本书开始阅读，支持 EPUB、PDF、CBZ、TXT 等格式 | 导入书籍（强调按钮） |
| 搜索无结果 | 书架搜索 0 本 | 没有找到“<关键词>” | 试试书名或作者中的其他字词 | 清除搜索 |
| 无目录 | 书没有导航数据 | 这本书没有目录 | 可以用 Ctrl+F 搜索，或按页翻阅 | 无 |
| 无标注 | 本书 0 条 | 还没有标注 | 选中文字后右键，选择“添加标注” | 无 |
| 书内搜索无结果 | 搜完 0 条 | 没有找到“<关键词>” | 已搜索全书 | 无 |

### 错误态

| 状态 | 触发 | 文案 | 动作 | 位置 |
| --- | --- | --- | --- | --- |
| 缺字体 | 启动时 `exr_font_open` 失败 | **缺少阅读字体**：EXReader 需要程序目录下的 Reader.otf。重新解压完整的安装包后再试。 | 重新检查 · 选择字体文件 · 退出 | 窗内整屏。现状是弹框后退出（`reader.c:6287`） |
| 文件损坏 | `EXR_FORMAT` | **打不开《<书名>》**：文件已损坏，或不是有效的 <格式> 文件。书架和阅读进度没有变化。 | 确定 | 对话框 |
| 编码错误 | `EXR_ENCODING` | **打不开《<书名>》**：文本编码无法识别。请转换为 UTF-8 后重新导入。 | 确定 | 对话框 |
| 读取失败 | `EXR_IO` | **打不开《<书名>》**：无法读取文件，它可能已被移动，或正被其他程序占用。 | 重试 · 取消 | 对话框 |
| PDF 密码 | `EXR_PASSWORD` | **《<书名>》有密码保护**：这个版本还不能打开加密的 PDF。 | 确定 | 对话框 |
| 格式不支持 | `EXR_UNSUPPORTED` | **打不开《<书名>》**：这个版本不支持该文件的格式。 | 确定 | 对话框 |
| 内存不足 | `EXR_MEMORY` | **内存不足**：关闭其他程序后再试。当前位置已保存。 | 重试 · 取消 | 对话框 |
| 文件过大 | `EXR_LIMIT`，导入 > 96 MiB | **文件过大**：<文件名> 有 <大小> MB，目前最多支持 96 MB。 | 确定 | 对话框 |
| 书库错误 | `EXR_DATABASE` | **无法读写书架数据**：重启 EXReader 后再试。如果问题还在，请保留 <数据目录> 并反馈。 | 打开数据目录 · 确定 | 对话框 |
| 进度未保存 | 保存进度失败 | 阅读位置没有保存。将在下次翻页时重试。 | 无 | 提示条，5 秒 |

每个错误都同时写入状态文本，供屏幕阅读器播报。

### 慢任务（大文件）

| 阶段 | 触发 | 文案 | 动作 |
| --- | --- | --- | --- |
| 0–800 ms | 任务开始 | 不显示 | — |
| 800 ms 起 | 导入中 | 正在导入 <书名>…… <百分比>% | 取消 |
| 800 ms 起 | 打开中 | 正在打开 <书名>…… | 取消 |
| 800 ms 起 | 重排中 | 正在重新排版…… | 取消 |
| 10 s 起 | 仍未完成 | 上一行之后加：文件较大，可能还需要一会儿。 | 取消 |
| 取消请求后 | 任务在释放 | 正在取消…… | 无 |
| 不可取消的提交段 | `job_commit_barrier` 成立 | 正在保存，马上就好。 | 无 |

- 显示方式：底部居中提示条，不遮挡阅读，不禁用窗口。
- 百分比只在有进度回调时显示，没有回调时不显示数字。
- 翻页任务超过 800 ms 才显示，避免闪烁。

### 删除确认

**从书架删除《<书名>》？** 这本书的阅读进度和标注也会一起删除，无法恢复。按钮：取消（默认）· 删除。

## 8. `--debug-ui` 模式

启动参数 `--debug-ui` 打开，默认关闭，普通用户界面中没有任何入口。开启后增加：

- 菜单栏“开发”（图标 `E90F`），列出下表全部 17 项。
- Ctrl+Shift+D 打开“开发面板”：一个非模态窗口，含 17 个原生控件，**控件 ID 与现状相同**，现有按 ID 定位的测试启动时加此参数即可继续使用。
- 面板控件走原有 `host_command` 路径，启用条件沿用 `host_update_controls`。

`--self-test`、`--drive`、`--evidence`、`--phase`、`--data`、`--library`、`--font` 的行为不变，与 `--debug-ui` 相互独立。
