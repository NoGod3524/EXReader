## 1. 版式与几何

### 1.1 停靠侧与层级

| 项 | 值 | 依据 / 理由 |
|---|---|---|
| 停靠侧 | **左侧** | DeckMark 的导航栏 `.thumbs` 放在左边（DM L606 `border-right`），右侧 `.side-panel` 放的是笔记、字幕这类内容。目录是导航，所以放左边。设置浮层挂在顶栏右侧，两者一左一右，不会在同一位置叠在一起 |
| 层级 | 第 1 层：盖在阅读面上，**不挤压版心、不重排** | 如果改成推挤布局，1280 宽下可用宽会变成 1000 − ε，落进第 3 步的窄档，打开目录就会重新分页，首行文字也会变。盖在上面就没有这些问题 |
| 与设置浮层 | 互斥：打开一个就关掉另一个 | 两者都是第 1 层的临时界面，同时开着时焦点归属说不清 |

### 1.2 尺寸

| 项 | 值 | 依据 / 理由 |
|---|---|---|
| 宽度 W | **280 px**（含右侧 1 px 发丝线） | 宽度值取自 DeckMark `.note-pop` 的 280（DM L1781），**用途是新的**。理由：1280 宽、默认正文 17 px 时，版心 34 em = 578 px，左边距 = (1280 − 578) / 2 = **351**。面板右缘到正文左缘还剩 **71 px**；正文 18 px 时（评审实测 612 px 版心）还剩 **54 px**。两种情况都不低于第 3 步“文字到边 ≥ 48”的口径，所以在默认字号下，面板打开时不会压到正文。没有用 `.side-panel` 的 348：18 px 正文下会压住 14 px 正文 |
| 窄窗口 | W = min(280, 客户区宽 − 56) | **新增**。窗口很窄时留出 56 px 的阅读面露边，方便点击外面关闭。56 = 顶栏高 |
| 大字号 | 不调整宽度，面板直接盖住正文左侧 | 24 px 正文时版心 816、左距 232，面板会盖住约 48 px 正文。面板是临时界面，点击条目后就关闭（§3.3），所以可以接受 |
| 上缘 | y = **56**，紧接顶栏下方 | 顶栏占 y 0–55，第 55 行是 `--line` 发丝线（G5-2）。面板不画自己的上边线，**直接借用顶栏发丝线** |
| 下缘 | 贴到窗口底边（y = 客户区高 − 1） | 停靠面板，DM `.side-panel` 同样通高 |
| 左缘 | 贴到窗口左边 x = 0 | 同上 |
| 高度（1280×800） | 744 px（y 56–799） | |

### 1.8 DPI

令所有值按 `s = DPI / 96` 缩放，四舍五入到物理像素。另有三条：发丝线 = max(1, floor(s)) 物理像素；选中竖条 = round(2s)；焦点环 = round(2s)。**新增**，理由：CSS 1 px 的线在 150% 下会变成 1.5 物理像素，抗锯齿后发虚；用整像素线才能做到取色误差为 0。

## 3. 交互与动效

### 3.1 展开 / 收起

| 项 | 值 | 依据 |
|---|---|---|
| 时长 | **180 ms**，展开和收起相同 | G5-6；DM L3213 `.modal` 同为 0.18s |
| 曲线 | `--ease` = `cubic-bezier(0.2, 0.8, 0.2, 1)`，展开和收起都用 | 令牌。收起不改用 ease-in。这条曲线头快尾慢，收起时面板很快离开视线，正合适 |
| 位移 | 水平方向：展开时 x 偏移从 −W 到 0（从左边缘滑入）；收起时反过来 | 面板停在左侧，只沿水平方向进出 |
| 淡入 | **不淡入**，整个过程不透明度都是 1 | 与 DM `rise-in`（L3198）的“淡入 + 4 px 位移”不同：那是给小浮层用的。面板盖在正文上，如果半透明，两层文字会叠成一片；面板不透明，正文只是被面板边缘逐步盖住 |
| 正文 | 完全不动，不重排，不变暗 | §1.1 |
| 参照点 | 第 45 ms 时进度约 0.77（面板右缘约在 x 215）；第 90 ms 时约 0.95（约 x 265） | 由 `--ease` 推算：x(s) = 0.6s − 0.6s² + s³，y(s) = 2.4s(1−s)² + 3s²(1−s) + s³ |
| 中途反向 | 动画进行时再点一次目录按钮或按 Esc：从当前位置开始反向，用时 = 180 ms × 已走过的比例，曲线不变 | **新增**：避免先跳到终点再退回 |
| 系统关闭动画 | `SPI_GETCLIENTAREAANIMATION` = FALSE 时，展开和收起时长都是 **0**：直接画出终态，中间帧数为 0；滚动条加宽也是 0 ms | G5-5 已定的退化规则；DM L3218 `prefers-reduced-motion` |

### 3.2 打开时的初始状态

- 列表自动滚动到**当前章节**行，让它在列表可视区里垂直居中；靠近开头或结尾、无法居中时，就滚到顶或滚到底。打开时**不做滚动动画**。
- 当前章节 = 目标位置不晚于当前阅读位置的最后一个目录条目。阅读位置还在第一个条目之前时（比如在封面），没有选中行。
- 焦点落在当前章节行（没有选中行时落在第一行）。按快捷键或 Tab 打开时显示焦点环，鼠标点开时不显示（§2.1）。

### 3.3 键盘

| 键 | 行为 |
|---|---|
| ↑ / ↓ | 焦点上下移一行，**不跳转、不改选中竖条**；焦点移出可视区时把列表滚到刚好露出该行。到第一行、最后一行就停住，不回绕 |
| Home / End | 焦点到第一行 / 最后一行 |
| PageUp / PageDown | 焦点上下移“可视行数 − 1”行 |
| Enter / Space | 跳转到焦点所在章节，然后关闭面板（见下），焦点交回正文 |
| Esc | 关闭面板，焦点回到顶栏目录按钮 |
| Tab / Shift+Tab | 面板打开时 Tab 顺序：目录按钮 → 设置按钮 → **目录列表**（整个列表只占一个 Tab 停靠点，进入时落在上次的焦点行）→ 正文 → 回到目录按钮。书名不可聚焦（G5-2：可操作元素只有目录、设置、正文） |
| 面板打开且焦点在列表上时 | ↑↓、PageUp/PageDown、Home/End、空格**只作用于列表，不翻书** |

### 3.4 鼠标与关闭规则

| 操作 | 结果 |
|---|---|
| 单击列表行 | 跳转，然后**关闭面板** |
| 再点顶栏目录按钮 | 关闭 |
| 点击面板外的阅读区 | 关闭面板，这次点击被吃掉，**不翻页** |
| 点设置按钮 | 关闭目录，打开设置（互斥） |
| 面板外滚动滚轮 | 正常翻书，面板保持打开，选中竖条跟着当前章节变 |
| 面板内滚动滚轮 | 滚动列表，每格 = 系统滚动行数 × 34 px（默认 3 × 34 = 102 px） |
| 改变窗口大小 | 面板保持打开，高度跟随窗口，宽度按 §1.2 |
| Alt+← 回旧面板 | 先关闭目录（不播放动画），再回旧面板 |

**点击行后关闭面板，理由：**

1. 点击目录的意图就是“去那一章”，跳转完成后面板已经没用了；
2. 字号大于 18 px 时面板会盖住正文（§1.2），不关闭就得再操作一次才能读；
3. 键盘用户按 Enter 后焦点直接回到正文，可以马上翻页，不必再按 Esc。

想连续看几章的人，按一次目录按钮就能回来，打开时会定位到新的当前章节。

**跳转与关闭的先后：**先完成跳转，并把新页面画到面板下面；**然后**才开始收起动画。这样面板滑走时露出的是新章节，不会先闪一下旧页。这一过程的空白帧计数也必须为 0。

## 4. 空状态与异常态

### 4.1 无目录的书

| 项 | 值 | 依据 |
|---|---|---|
| 面板 | 照常打开，头部照常显示“目录”，**不显示条目数和分隔线以下的列表** | 让用户知道“目录是空的”，而不是“按钮没反应” |
| 主文案 | **这本书没有目录** | G5-6 字面要求 |
| 主文案样式 | 16 px / 650 / `--text`（`#1b1b1f` / `#f2f2f4`） | DM L1507–L1511 `.notes-empty h3` |
| 次文案 | “可以用 PageDown 或滚轮继续翻页”；14 px / 400 / `--text-2`，行高 1.6 | DM L1512–L1515；**新增**文案，告诉用户接下来怎么办 |
| 两行间距 | 10 px | DM L1503 `gap: 10px` |
| 位置 | **水平居中、靠上**，不垂直居中：内容块上缘距头部分隔线 56 px，左右内边距 28 px（文字区 224 px，次文案自动折行，行内居中） | DM L1504 `padding: 56px 28px`、L1505 `text-align: center`。DeckMark 的空状态都是靠上的（`.captions-empty` 上距 72，L947），在 744 高的面板里垂直居中会显得悬空 |
| 焦点 | 落在面板容器上，不显示焦点环；Esc 关闭 | 没有可选条目 |
| UIA | 空列表加一段静态文字，名称 = 主文案 | |

### 4.2 读取失败 / 读取中

| 情况 | 处理 |
|---|---|
| 目录解析失败 | 布局同 4.1；主文案“目录无法读取”，次文案给出简短原因（沿用 42fca211 保留下来的失败信息），颜色 `--text-2`。**新增**：与“没有目录”分开，免得把故障说成书本身的问题 |
| 读取超过 400 ms | 400 ms 前什么都不画；之后在主文案的位置显示“正在读取目录…”，14 px / `--text-3`，不加转圈动画。**新增**：本地 EPUB 一般瞬间就能读完，过早给出加载提示只会闪一下 |

### 4.3 长目录（500 行以上）的虚拟滚动策略

只给策略，不写实现：

1. **行高固定为 34**（各层都一样），所以滚动位置和行号可以直接换算：首行号 = floor((scrollY − 8) / 34)，内容总高 = 8 + N × 34 + 28。不需要事先测量每一行。
2. **只画可视区的行**，上下各多画 1 行防止滚动时露白；1280×800 下每帧最多 22 行。
3. **文字排版按需做并缓存**：省略号截断的结果在某行第一次画出时才计算，并缓存下来；面板宽度或 DPI 改变时整体清空缓存。打开 5000 行的目录，耗时不应随 N 增长。
4. **定位当前章节**用二分查找（条目按阅读位置排好序），打开时直接设置 scrollY，不做动画。
5. **滑块**：长度 = max(32, 可视高² / 内容总高)；拖动时把位置线性映射到内容高。
6. **跳转距离超过一屏时不平滑滚动**（Home/End、PageUp/PageDown 连按），直接定位。
7. **UIA** 由列表控件代理报告真实条目总数，读屏软件能读到“第 k 项，共 N 项”；不要为了虚拟化把条目数报少。
8. **预算**：滚动一帧（排版 + 渲染）p95 不超过 4 ms（**新增**，这是第 4 步 25 ms 整帧预算中留给目录面板的份额）。

## 5. 与顶栏“目录”按钮的关系

按钮几何沿用评审 P0-3：32×32，圆角 9，字形 18 px（描边 1.5），1280 宽下目录按钮在 x 1198–1229、设置按钮在 x 1236–1267，两者间距 6，右边距 12，垂直居中于 56 高的顶栏（y 12–43）。

| 状态 | 按钮底 | 字形色 | 依据 |
|---|---|---|---|
| 面板关闭 · 常态 | 不画（顶栏 `#ffffff`） | `--text-2` `#5c5c65` | DM L167 |
| 面板关闭 · 悬停 | `--surface-2` `#efeeea` | `--text` `#1b1b1f` | DM L170–L172 |
| 面板关闭 · 按下 | `--surface-3` `#e7e6e1` | `--text` | 评审 a 节 |
| **面板打开（on）· 常态** | 不画 | **`--accent` `#4553e0`** | DM L174 `.icon-button.on { color: var(--accent) }` |
| 面板打开 · 悬停 | `--surface-2` `#efeeea` | `--accent` `#4553e0` | **与 DeckMark 不同**：在 DeckMark 里，`:hover` 选择器优先级更高，悬停会把 on 按钮的字形改回 `--text`。这里保持靛蓝，免得悬停时看不出面板开着 |
| 面板打开 · 按下 | `--surface-3` `#e7e6e1` | `--accent` | |
| 焦点 | 叠加 2 px `--accent` 外环，offset 2，圆角 11 | DM L102–L104；评审 a 节 |
| 深色对应 | 常态字形 `#b3b3bc`、悬停底 `#28282c`、按下底 `#313136`、on 字形 `#7c88ff` | 令牌深色表 |

- on 态**不加底色**：DeckMark 在 `.lecture-bar .bar-tools`（L3383）里给 on 按钮加了 `--surface` 底和 `--shadow-sm`，前提是按钮放在 `--surface-2` 的分组槽里。EXReader 顶栏本身就是 `--surface`，再加同色底等于没加，只靠字形变靛蓝表示开着。
- 面板打开时再点一次按钮：**收起**。
- 动画进行中，按钮的 on 态在点击的同一帧就切换，不等动画结束。
- UIA 名称一直是“目录”，不随开关状态加后缀；按钮仍是 G5-2 定义的三个可操作元素之一。
