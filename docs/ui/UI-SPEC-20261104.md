# EXReader Windows UI 令牌（2026-11-04，2026-11-05 改为扁平化）

**2026-11-05 修订**：方向从“极简、纸白、分割线分层”改为“扁平化 + 现代审美”。本文整体替换旧令牌；旧的 `#FBFBF9` 纸白底、`surface` 加 `divider` 分层、4 DIP 间距、`radius` 0/4/8 全部作废。本轮只改文档，不改代码。

单位：DIP（1 DIP = 1/96 英寸），物理像素 = DIP × DPI / 96。实现中不得出现本文之外的间距、字号、颜色字面值。

## 0. 三条原则

1. **所有控件自绘。** 禁止出现 Win32 默认控件的 3D 边框、凹陷、`WS_EX_CLIENTEDGE`、系统灰按钮。这是旧界面“丑”的根因。
   - 实现方式定为：保留每个控件自己的 HWND（`BS_OWNERDRAW` 按钮、`LBS_OWNERDRAWFIXED` 列表等），外观全部自己画。
   - 原因：原生 HWND 自带的 UIA 代理（名称、角色、Invoke、Selection）继续有效，不必为每个控件手写 UIA provider。
   - 正文区已经是自定义窗口，保持不变。
2. **层级用明度差，不用分割线。** 三层底色（§4.1）区分区域。只有顶栏下沿保留一条 6% 透明度的发丝线，用来在滚动内容上分界。
3. **全局只有一个强调色。** 只用于可交互元素的状态（hover、pressed、focus）和选中态，不用于装饰、标题或图标常态。

**例外**：焦点描边 2、发丝线 1 是描边粗细，不是间距。

## 3. 字号与行高

界面字体：`Segoe UI Variable`，回退 `Segoe UI`；CJK 回退 `Microsoft YaHei UI`。**层级只用字号和颜色区分，不用伪粗。**

| 令牌 | 字号 | 行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| `type.display` | 28 | 1.2（33.6） | 400 | 空状态标题 |
| `type.title` | 20 | 1.3（26） | 400 | 面板标题、对话框标题 |
| `type.body` | 17 | 1.6（27.2） | 400 | 正文默认、顶栏书名（书名用 600） |
| `type.ui` | 14 | 1.45（20.3） | 400 | 按钮、列表、设置值、页码、作者 |

**字重规则：**
- 只允许 400 和 600 两档。600 只用于顶栏书名和面板里的当前分组名。
- 600 必须落到字体的真实字面：拉丁字用 `Segoe UI Semibold`；CJK 的 `Microsoft YaHei UI` 没有 600，按 DirectWrite 字重匹配落到真实的 Bold（700）字面。
- 实现时检查 `IDWriteFontFace::GetSimulations() == DWRITE_FONT_SIMULATIONS_NONE`。不等于 NONE 就是伪粗，算缺陷。

### 正文（引擎排版，非 DirectWrite）

| 令牌 | 值 |
| --- | --- |
| `read.font.default` | 17 |
| `read.font.steps` | 14, 15, 16, 17, 18, 20, 22, 24, 28, 32 |
| `read.line` | 1.6 |
| `read.paragraph` | 0.8em（字号 17 时 13.6） |
| `read.measure` | `clamp(28em, 34em, 可用宽 − 96)`，居中（见下） |
| `read.edge.min` | 48（文字到窗口左右边的下限） |
| `read.pad.v` | 32（正文到顶栏下沿、到页码上沿） |
| `read.margin` | 0（引擎 `page.margin`；留白全部由宿主布局给出） |

**版心**（2026-11-05 owner 决策 2）：`width = clamp(28em, 34em, 可用宽 − 96)`，即 `max(28em, min(34em, 可用宽 − 96))`，居中。
- 不设字号上限。680 只在默认字号附近近似成立（字号 20 时 34em = 680），不作为硬上限。
- 判据：每行汉字 28–34（拉丁文本 65–75），文字到左右窗口边各 ≥ 48。

默认客户区 1280 宽（可用宽 − 96 = 1184），任何字号都取 34em：

| 字号 | 版心 | 每行汉字 | 每行拉丁（0.466em 估算） |
| --- | --- | --- | --- |
| 14 | 476 | 34 | 73 |
| 17 | 578 | 34 | 73 |
| 20 | 680 | 34 | 73 |
| 24 | 816 | 34 | 73 |
| 32 | 1088 | 34 | 73 |

**窄窗口：边距优先**（2026-11-05 owner 决策）：

```text
lim   = 可用宽 − 96
width = lim < 28em ? lim : clamp(28em, 34em, lim)
```

左右各 48 的边距永远成立。窗口放不下 28em 时，版心让给边距，每行少于 28 字。

**验收分两档**（“窗口宽”按**客户区宽**算，即可用宽；外框宽约多 16，按外框算时 1000 档在字号 32 会落到 27.75 字）：

| 档 | 判据 |
| --- | --- |
| 客户区宽 ≥ 1000 | 每行汉字 28–34（拉丁 65–75），左右边距各 ≥ 48 |
| 客户区宽 < 1000 | 左右边距各 ≥ 48，每行汉字 ≥ 18 |

按公式算出的两档结果（**计算值，不是实测**；实测在第 3 步）：

| 客户区宽 | 字号 | 版心 | 每行汉字 | 左右边距 | 判定 |
| --- | --- | --- | --- | --- | --- |
| 1280 | 14 / 17 / 20 / 24 / 28 / 32 | 476 / 578 / 680 / 816 / 952 / 1088 | 34 | 402 / 351 / 300 / 232 / 164 / 96 | 全过 |
| 1000 | 14 – 24 | 34em | 34 | ≥ 92 | 过 |
| 1000 | 28 / 32 | 904 / 904 | 32.3 / 28.2 | 48 / 48 | 过 |
| 999 | 28 / 32 | 903 / 903 | 32.2 / 28.2 | 48 / 48 | 过（< 1000 档：≥ 18 字） |
| 720 | 14 / 17 | 476 / 578 | 34 | 122 / 71 | 过 |
| 720 | 20 / 24 / 28 / 32 | 624 | 31.2 / 26.0 / 22.3 / 19.5 | 48 | 过（< 1000 档） |

- 1000 这条线正好保证字号 32 的 28em（896）放得下：1000 − 96 = 904。
- 最小客户区 720 下，字号 32 每行 19.5 字，仍满足 ≥ 18。字号超过 34.6 时才会跌破 18，而字号上限是 32。
- 拉丁文本：版心低于 30.3em 时每行少于 65 个拉丁字符，所以拉丁判据只在 ≥ 1000 档、且版心 ≥ 30.3em 时适用。

引擎入参换算：

```text
page.width_px  = round(版心 × dpi / 96)
page.height_px = round((正文区高 − 32 − 32 − 24 − 32) × dpi / 96)   # 上留白、页码上间距、页码区、下留白
page.font_size = font × dpi / 96
page.margin    = 0
```

显示比例恒为 1:1，不得拉伸。

## 4. 颜色

### 4.1 三层底色

层越高越“近”：浅色主题里越高越白，深色主题里越高越亮。相邻层只靠明度差区分，不画边框。

| 层 | 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- | --- |
| 0 | `color.layer.page` | `#FFFFFF` | `#121316` | 正文页、顶栏、书架内容区 |
| 1 | `color.layer.side` | `#F7F7F8` | `#191A1D` | 左栏、停靠面板（目录、标注） |
| 2 | `color.layer.float` | `#FFFFFF` + 阴影 | `#222327` | 浮层：设置面板、菜单、提示 |

浅色主题的第 2 层与第 0 层同为白色，靠 §6 的阴影分开；深色主题里阴影几乎看不见，所以第 2 层提亮到 `#222327`。

### 4.2 文字与强调

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `color.text` | `#1D1D1F` | `#E8E8EA` | 正文、主要文字、图标常态 |
| `color.text.secondary` | `#6E6E73` | `#A1A1A6` | 页码、作者、标签 |
| `color.text.disabled` | `#AEAEB2` | `#5C5D63` | 禁用文字和图标 |
| `color.accent` | `#1A73E8` | `#1A73E8` | **全局唯一强调色**：交互态、选中态、焦点描边 |
| `color.on-accent` | `#FFFFFF` | `#FFFFFF` | 强调色填充上的文字 |
| `color.error` | `#C5221F` | `#F28B82` | 错误文字（不是强调色，只用于报错） |
| `color.hairline` | `rgba(0,0,0,.06)` → `#F0F0F0` | `rgba(255,255,255,.06)` → `#202124` | 顶栏下沿 1 DIP |
| `color.selection` | 强调色 30% → `#BAD5F8` | 强调色 35% → `#15355F` | 正文选区 |

- **强调色取值**：选 `#1A73E8`，不选 `#0A84FF`。后者在白底上只有 3.65，作文字不够 4.5。
- **深色主题的局限**：`#1A73E8` 在深色页上只有 4.12，因此深色下强调色**不作为小号文字颜色**，只用于填充、描边和图标，选中态靠底色叠加表示。
- **深色发丝线**：owner 给的是 `rgba(0,0,0,.06)`，在深色底上不可见，深色改用白色 6%（owner 2026-11-05 已确认）。

传给引擎的背景：浅色 `0xFFFFFFFF`，深色 `0x121316FF`，由 `exr_render_page_background` 接收。

## 6. 阴影

只给第 2 层浮层，其余一律无阴影：

```text
shadow.float = 0 2px 8px rgba(0,0,0,.08)
```

Direct2D 实现要点：`ID2D1HwndRenderTarget` 不支持效果图。阴影的画法是对浮层形状做一次高斯模糊（σ = 4）的离屏位图，缓存起来，只在尺寸变化时重建。

## 7. 交互态

每个可交互控件都有五态：normal、hover、pressed、focus、disabled。可选控件再加 selected。

**叠加规则：**
- hover / pressed 是在控件**所在层的底色**上叠加强调色，不另设灰色。
- 焦点用 2 DIP 实线 `accent` 描边，沿控件圆角外扩 2 DIP，只在键盘导航时显示。

| 状态 | 规则 | 浅色 page / side 层结果 | 深色 page / side / float 层结果 |
| --- | --- | --- | --- |
| hover | 强调色 6% 叠加 | `#F1F7FE` / `#EAEFF7` | `#121923` / `#191F29` / `#222833` |
| pressed | 强调色 12% 叠加 | `#E4EEFC` / `#DCE7F6` | `#131F2F` / `#192535` / `#212D3E` |
| focus | normal + 2 DIP `accent` 描边，外扩 2 | — | — |
| disabled | 文字和图标 `text.disabled`，不响应 hover | — | — |
| selected | 底同 pressed；列表行左侧 3×16 `accent` 圆角竖条 | — | — |

| 控件 | normal | 形状 |
| --- | --- | --- |
| 圆形图标按钮 | 底透明，图标 20 `text` | 直径 40 圆，hover/pressed 填满圆 |
| 普通按钮 | 底透明，字 `text`，**无边框** | 圆角 8，高 32，左右内边距 16 |
| 主按钮 | 底 `accent`，字 `on-accent`；hover/pressed 改为在强调色上叠加 8% / 16% 黑 | 圆角 8 |
| 输入框 | 底为所在层的 hover 色，无边框；focus 时 2 DIP `accent` 描边（内描，不外扩） | 圆角 8，高 32 |
| 分段控件 | 底同输入框；选中段底 `accent`、字 `on-accent` | 外框圆角 8，段内圆角 6 |
| 列表行 | 底透明 | hover/选中底圆角 8，左右各缩进 8 |
| 书卡 | 封面无边框；hover/pressed 是整张卡（封面加书名区，外扩 8）的叠加底，不加阴影 | 封面圆角 10，叠加底圆角 14 |
| 正文翻页区 | 无可见变化 | — |

## 8. 动效

- **只有面板展开和收起有动画**：180 ms，ease-out（`cubic-bezier(0, 0, 0.2, 1)`），只动位置和不透明度。适用于设置浮层、目录和标注面板。允许范围 150–200 ms。
- 翻页、滚动、hover、pressed、焦点切换一律**无动画**，即时切换。
- 系统关闭动画时（`SPI_GETCLIENTAREAANIMATION` 为 FALSE），面板动画时长取 0。
