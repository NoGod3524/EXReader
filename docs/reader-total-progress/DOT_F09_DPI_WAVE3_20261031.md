## Purpose

The earlier DPI package was the lightweight EXReaderProduct target and has none of the dialogs. Wave3 contains the metadata, account, in-book search, directory, reading-record, organization and preferences windows and the compact layout. This run (1) rebuilds Wave3 with the DPI change and runs the repository's existing native UI gates (compact UI, Wave3 UI, TXT progress, account/sync, organization, forward scan) as a regression check at the runner's 96 DPI, where every DPI helper is the identity, and (2) exports the package for a manual 125% check of the dialogs with Narrator's highlight.

## Limits
