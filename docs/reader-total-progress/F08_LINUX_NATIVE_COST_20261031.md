# Linux complete product generation cost

The test-only module follows the existing native host queue into the SDK worker, retains the exact idle result callback, binds the resulting pixbuf to its accepted page generation, and observes its actual GtkImage draw. It measures worker-pop to corresponding frame after-paint plus a measured XSync(False) fence. This includes actual parse/layout/raster work, UI handoff and queue delay, result application, GTK layout/draw and processing of the preceding X11 connection commands. Native input-to-completion and queue/worker/apply/draw/fence stages remain separate raw fields. The fence changes scheduling; its entire measured wait stays included as a conservative upper bound. This is native server completion, not monitor scanout.

Every submitted job and native frame remains in the census, including non-frame work, superseded generations, missing draws, native errors and background shelf preparation. A missing required visible generation prevents complete evidence. Startup's first page generation is reported separately and remains in the all-page denominator. Page turns, fonts, locate/jump and other reader generations are predeclared groups. Visible shelf worker generations use the same complete boundary. Cached shelf composition reports the conservative native-input-to-completion upper bound, which includes input queue and animation. Reader/body GDK phase observations are labelled separately and never substituted for worker generation cost.

Production sources, SDK, feature flags, 2202-book corpus, original 32+12 launches/760 samples and the separate six causal launches remain unchanged. A synthetic producer injects 50/80ms worker delays and verifies both remain in full cost; removing a completion must retain a missing generation. Full product sampling keeps the original 90-minute job and all original operation timeouts; controls and audit are bounded to 20 minutes each. Budgets remain P95 16.67ms and P99 33.34ms, TTI 2000ms and RSS 512MiB. The report remains a candidate for cross-platform gate review; F08 is not automatically marked accepted.
