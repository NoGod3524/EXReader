## Shared deletion projection regression and correction

source `8f6810f197994347052aa152088f2384e318719b`, reproduced the defect in both
legacy and raw formats: cold replicas used ID-only names, lost shelf parent and
ordinal, and missed memberships under deleted groups. Both cold and warm page

`apps/reader/revisions/src/revisions.cpp`. Group tombstones derive display fields
from the nearest retained put/restore ancestors, keeping the deleted flag and
using a deterministic identity-only fallback for differing branch snapshots.

local writes continue to require active groups. History, outbox, SDK and the
three frozen production blobs remain unchanged by this correction.
