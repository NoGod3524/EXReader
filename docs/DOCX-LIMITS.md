# DOCX 保留与编辑边界

T1 的目标是保留源 OPC 部件和非目标 OOXML，而不是实现 Word 排版引擎。测试分别验证无修改往返和只替换正文一个文本 run；后者逐部件比对“原文仅替换指定文字”的独立结果。30 个夹具与完整数字见 [DOCX-REAL-RESULTS.md](DOCX-REAL-RESULTS.md)。

| 结构／明确放弃的能力 | 原因 | 保守行为 |
| --- | --- | --- |
| Word drawing canvas、SmartArt、组合图形的内部编辑 | core 没有画布、连接器、分组变换或 Word 专有布局模型；这些对象还可能依赖多个关系部件 | 导入为 opaque run/block；保留原 XML、AlternateContent 与原 OPC 部件。文字接口拒绝 opaque run，返回 `EXR_UNSUPPORTED`。T1 的组合图形夹具验证分组及 VML 回退保留；drawing canvas 的内部语义不在覆盖范围内。 |
| 浮动图片的环绕布局、相对定位、层叠顺序的可视化编辑 | 现有图片模型只暴露新图片的载荷与尺寸，没有 anchor、wrap、z-order 模型 | 现有 `wp:anchor` 和 `wp:wrapSquare` 整个保留；修改相邻正文不改这些属性，不把浮动图转换为内联图。 |
| PAGE／NUMPAGES／DATE／REF／TOC，包括中文域代码的重新计算 | 需要 Word 的分页、时钟、书签及目录更新语义；core 不提供域求值器 | 保留域指令、begin/separate/end、缓存结果、dirty 标志及关联书签。正文改字不更新缓存结果；由支持域更新的应用重新计算。 |
| 合并单元格、嵌套表、带复杂 opaque 内容单元格的文字替换 | 表格编辑模型使用物理行列；不能可靠拆解合并网格或递归表格内部编辑语义 | 原始表格／单元格 XML 保留。`exr_edit_table_set_cell_text` 对受保护单元格返回 `EXR_UNSUPPORTED`；插删行不能截断纵向合并链。正文邻接编辑仍保持表格字节。 |
| 多栏、脚注每页重编号、脚注表格的编辑和分页重算 | `exr_edit_section` 不暴露栏；脚注未纳入可编辑正文模型，重编号需要页布局结果 | `w:cols`、`w:footnotePr` 和 footnotes 部件原样保留。正文文字替换不重写这些结构，也不承诺 Word 页码或脚注布局重新计算。 |
| 主题字体、完整样式继承的交互式编辑／字体匹配 | run 属性接口只覆盖显式字体、字号、粗体、斜体、颜色；没有完整主题／样式编辑模型 | styles、theme、numbering、settings 部件保持字节；主题字体引用和未覆盖的直接格式继续保留。显式设置字体才覆盖相关字体属性。 |
| 文本框内部、批注正文和书签范围的语义编辑 | 这些内容作为 opaque XML 或独立部件存在；没有评论／书签范围命令及引用重绑定器 | 单一正文 run 改字保留锚点顺序、ID、批注部件及文本框 XML。文字接口拒绝 opaque run；不提供跨锚点的文字替换或范围重绑定命令。 |
| UTF-16／非 UTF-8 主文档 XML 的可编辑导入 | 保留层使用原始字节跨度；直接混入 UTF-8 输出会破坏源编码 | 在导入时明确返回 `EXR_UNSUPPORTED`，输出模型为空，不生成混合编码文档。支持 UTF-8、US-ASCII XML。 |
| 原 ZIP 文件的压缩流、时间戳、目录属性和整体 SHA-256 不变 | 写出会重新构建 ZIP；模型持有 OPC 部件内容，没有原 ZIP 容器元数据 | 验证每个解压部件的字节／哈希。无修改时部件全部相等；改字时仅主文档目标文本不同。整体 DOCX ZIP 哈希变化不等于内容丢失。 |
| 数字签名在修改后继续有效 | OOXML 签名覆盖原有内容；修改正文会改变被签名数据 | 原签名部件随其它 OPC 部件保留；编辑后原签名失效。调用方必须重新签名，不能沿用原签名的有效性结论。 |

`exr_edit_set_run_text` 只替换一个可编辑 TEXT run，保留段落和 run ID、直接格式、XML 模板及相邻 opaque 内容；参与同一事务、撤销与重做。非法 UTF-8、XML 禁止字符及错误索引被拒绝，失败不改变文档。源文件本身不被覆盖。

原 #117 校验器的六项计数不能发现注释／处理指令换位。T1 增加完整主文档树（含注释、处理指令、文本与 tail）、其它结构指纹及 OPC 部件字节比较；格式 profile 是否符合“Letter／TNR 12pt”等新建文档规范，不作为真实文档保留率的替代指标。
