## Real before/after product-commit death

Twelve additional cases cover both actual commit boundaries: four formats
forward across versions, plus same-version TXT controls. Only the uninstalled
probe links `--wrap=reader_rc_apply`. The wrapper stops immediately before the
actual API call, or immediately after its successful real commit and before
the owner clears its private durable request. The original pending request has
already been flushed by the unchanged host. The parent observes the marker,
retains the exact private bytes and sends SIGKILL to the actual process.

Reopening never auto-replays. Explicit real-host retry must retain original ID,
parser and complete wire bytes: `created=1` after precommit death, `created=0`
after already committed death, and `created=0` for exact explicit replay.
The old request bytes are copied verbatim for that replay, never regenerated.
Actual retry output, request SHA-256, SIGKILL status and actual boundary marker
are bound into the same-source report. Successful retry also passes the actual
host jump and exact public recapture.
