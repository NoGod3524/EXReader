## 测量口径

每次样本都是一个**独立的新进程**：`EXReader.exe --font Reader.otf --data <profile>`。
所有操作由外部观测者投递到该进程**真实存在的 Win32 控件**上，并从同一控件读回结果：

| 操作 | 原生输入 | 观测点 |
| --- | --- | --- |
| 首屏可交互 | `SendMessageTimeoutW(WM_NULL)` 到主窗口 | 产品书架页 50 行已交付（详情按钮已由 product_ready 启用、行文本不再是旧 SDK 列表格式）**且** UI 线程完成一次同步消息往返 |
| 书架分页 | 列表 `WM_MOUSEWHEEL` 滚到底部 | 列表由 50 行增至 100 行（keyset 下一批） |
| 搜索 | 搜索框 `WM_SETTEXT` | 列表变为该过滤条件的 50 行结果（含宿主 200 ms debounce） |
| 打开书籍 | `LB_SETCURSEL` + 打开按钮 `BM_CLICK` | 页码标签首次出现合法页号 |
| 书内翻页 | 下一页按钮 `BM_CLICK`（每次启动 8 次） | 页码标签页号/章号发生变化 |
| 继续阅读 | 新进程启动（宿主自动恢复上次书与页） | 页码标签恢复到上次页号，并与上一进程记录逐次比对 |
| 导入期间输入响应 | 导入按钮 `BM_CLICK` 后持续采样 | 导入忙窗口内 `WM_NULL` 往返与路径框回显 |
| 工作集峰值 | 观测进程每 20 ms 读一次 `GetProcessMemoryInfo` | `PeakWorkingSetSize` / `PrivateUsage` |

这些消息投递到真实原生控件并由产品 UI 线程处理；它们**不是** `SendInput` 级别的硬件注入。
上报值是**外部端到端 UI 延迟**：从提交原生输入消息到控件状态可被外部观测为止。

**帧时间未测。** 该路径没有暴露应用内帧或 present 信号，因此本包不产出、也不推断
帧时间；任何数值都不能称为应用帧时间，也不代表「丝滑」。离散度包含观测轮询粒度
（一次 `WM_NULL` 往返 + 3 ms sleep）与云端共享 runner 的负载。

冷/热策略：冷启动组每次从种子库文件复制一份全新 profile（无产品目录库、无
`host.ini`），因此每次冷启动都重建产品目录；热启动组与阅读组复用已建好的 profile。
操作系统磁盘缓存与同宿负载**不受控**，冷/热只描述 profile 策略。

## 样本矩阵

四组各 12 次实测进程启动（共 48 次），另有 2 次准备启动（建产品目录、建阅读 profile，
单独计数；合计 50 次进程启动）：

| 组 | profile | 采集 |
| --- | --- | --- |
| `cold_shelf` | 每次全新复制 SDK 库文件 | 首屏、书架分页、搜索、清空、峰值 |
| `warm_shelf` | 共享已建 profile | 首屏、书架分页、搜索、清空、峰值 |
| `reading` | 共享阅读 profile（2202 + 固定多页书） | 打开/继续阅读、8 次书内翻页、峰值 |
| `import` | 每次全新复制 SDK 库文件 | 首屏、导入期间输入响应、导入后可见性、峰值 |

首批 50 行与搜索过滤结果在每次样本内都会被核对（`Shelf 0000..0049`、
`Author %_!` 的 17 倍数行、书内页号单调前进、继续阅读页号与上次记录相等）；
任何不符即记为测量失败而不是静默通过。

## 未授予与限制

- 未授予产品性能「达标」：没有数值预算，`performance_accepted=false`。
- 未测帧时间、合成器时序、输入延迟下限或掉帧；外部端到端延迟不能替代帧信号。
- 磁盘缓存与云端同宿负载未受控，冷/热只描述 profile 策略；跨次绝对数值会有波动。
- 冷启动 5.13 s 属于「每次重建 2202 本产品目录」这一已记录的产品行为，本包不据此
  主张或否定任何优化。
- 本包不重复认证功能验收、读屏、真机或完整产品；这些仍未由本包授予。
- 原失败保留：本轮之前的五次运行均为失败并保留在运行历史里：
  `40076519862` 打包断言把 manifest 散列当成字节数比较、工件身份步骤缺少令牌；
  `40077316443` 主窗口在自身 WM_CREATE 建子控件期间已可被枚举，首次读控件即失败；

  （目录只有 22 行）；`40078522386` 导入夹具标题与 TXT 派生标题不一致，导入后检索超时；
  `40079602783` 16 MiB 单文档 TXT 导入后不可见，改用固定多章 EPUB。
  以上均按根因修复，未删除断言、未改弱检查，也未把失败改记成预期拒绝。
