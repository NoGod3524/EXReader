# 版本分配

当前源码、头文件、运行库和安装SDK统一使用 **3.40.0 开发版**。
全部历史按更新规模重新梳理，详见根目录[完整更新日志](../CHANGELOG.md)。
更新日志包含每批功能与修复、提交日期、旧编号、新编号及全部提交索引。

## 编号规则

- 超大更新：主版本加一，例如3.33.0 → 4.0.0。
- 中等更新：次版本加一，例如3.32.0 → 3.33.0。
- 小 bug 修复：补丁版本加一，例如3.33.0 → 3.33.1。
- 升主版本或次版本时，后续段归零。同一更新批次的实现、测试和验证合并编号；纯文档与编号整理归入对应批次。
- 核心与可选组件可按自身更新规模独立发布；总SDK版本反映整体更新。
- ABI epoch、数据库schema和产品版本分别管理，当前分别为1、6、3.40.0。
