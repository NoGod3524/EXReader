# Windows 简洁原生界面候选

起点 `25bc0c67971f81491f50e0a3caaaf7e509bb7e35`。
独立分支 `codex/reader-windows-compact`，默认关闭的构建选项
`EXR_READER_WINDOWS_COMPACT`，独立 Windows 范围已通过。

开启时，默认书架只显示搜索、继续阅读、打开、导入和书籍列表。
打开书籍后显示阅读区域、页号、前后翻页和返回书架。低频功能进入原生菜单：
云盘、账号、分类、搜索、目录、阅读记录和设置均调用现有处理入口。
“更多操作”展开原有完整面板，保留选文、笔记编辑和已有控件。
`Ctrl+O` 打开系统文件选择器，`Alt+←` 返回书架；原 `Ctrl+L` 阅读记录等快捷键保留。

界面层只调整显示、布局、焦点和命令路由，不新增线程或第三方依赖，
不直接访问 SDK、产品修订、同步或数据库。SDK3.41、MAX2、schema1 和旧 wire 不改。
普通构建默认 OFF；守卫移除候选条件块后逐字比对起点的旧宿主源代码。

云端工作流先完整保留默认 OFF 的 Windows 原套件、F3 25、真实原子保存13和旧拒绝对照，
随后用同一安装前缀单独构建真实 compact ON 产品。新增检查使用系统选择器、真实控件和菜单、
硬件快捷键、四格式阅读、翻页、笔记提交、对话框、缩小窗口和进程重开；截图随同原工件保存。
严格汇总复用全部旧判定，再核对 compact 程序、配置、具名检查和实际截图身份。

所有编译、语法检查、夹具、测试和工件解析只在 Actions 执行。
这份候选不改变正在运行的共同源码验收，
也不授予其他平台的界面、帧时间预算或完整产品验收。
