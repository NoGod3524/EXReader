# Windows 阅读设置提交边界修复候选

边界钩子只暂停在真实公开保存调用前后，取消通过原宿主窗口命令处理器进入。
负对照仅恢复旧的提交后取消否决，要求检测出磁盘新值与内存旧值不一致。
所有构建、夹具、UI 执行、协议负例和工件核对均在 Actions。
