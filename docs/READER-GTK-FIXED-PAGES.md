## 声明范围

GTK 宿主通过已安装 SDK 的公开 API 导入、打开 PDF 和 CBZ，不依赖 WebView。
PDF 原文件上限 32 MiB，先以 64 KiB 分块复制到私有匿名文件，公开 file 入口通过
仍存活的 `/proc/self/fd` 路径重复打开同一份快照；CBZ 使用流式来源导入。精确原字节去重，原件保存在 SDK
书库内，产品目录单独保存来源摘要与 `fixed_page` 映射。

固定页使用 `exr_library_fixed_source`、`exr_fixed_render` 和独立文本快照。默认长边
不超过 1080 像素，缩放输入为 25–400%，任一位图边超过 2048 像素则拒绝本次操作，
保留已接受的帧和缩放。F5/F6 在固定页为缩放，在重排书仍为字号。

页号只在 GTK 接受帧后提交。命令和提交携带页号，拒绝旧页操作。取消、渲染或标注
查询失败不替换当前阅读会话。固定页进度通过公开 `exr_library_update` 保存；设置
保存缩放，重启从书库恢复原书与页号。

原生文本面板支持系统选择和复制。标注从存储原件捕获 `page_id` 与引文前后文；只有
公开锚点解析返回 `FOUND` 才导航。重复引文的歧义不按旧偏移猜测。无文本的 CBZ 页
可阅读，但不能生成文本标注。
