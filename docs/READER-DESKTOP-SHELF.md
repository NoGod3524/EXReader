## 共用目录接口

`reader_catalog_query_page` 使用 `(sort_title,book_key)` 做双向 keyset。每次最多
200 条，反向结果按倒序交付，由界面翻转后插入头部。标题/作者搜索为字面子串，
百分号、下划线和感叹号没有特殊语义。大小写遵循 SQLite 内建规则：ASCII 不区分
大小写，其他 Unicode 按 UTF-8 内容匹配；不声明多语言 case folding。

`reader_catalog_find` 在当前过滤条件下查找稳定书籍 key，供视口恢复使用。
标题改动后返回当前排序值；已删除、已过滤或缺失的书返回不存在，宿主应回到首批，
不沿用过时索引。回调字符串仍为借用，返回前复制。owner 线程及禁止重入规则保留。

原单向 `reader_catalog_page` 保留，转调相同的只读实现。原十二组目录事务、所有权、
保留历史、触发器、分页索引和拒绝检查不替换。

新三平台 Actions 检查使用 2500 条独立产品 metadata（2499 可见、一条墓碑），
验证正反完整遍历、130 个同名项、标题作者及字面符号/UTF-8 搜索、稳定 key 恢复、
改名、输入限额、callback 早停/重入拒绝，及实际执行 SQL 的正反索引范围计划。
这些是原生目录测试，尚不授予 UI 流畅性、SDK 导入或跨设备同步信用。
