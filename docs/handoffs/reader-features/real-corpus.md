# F5：真实文档兼容性验收

先读[共同约束](README.md)，从固定起点创建`codex/reader-real-corpus`。
本包补真实书籍/文档证据，不修改引擎或用差分参考替代实际原生阅读结果。

## 文件归属

仅新增`tests/reader_real_corpus/**`、`.github/workflows/reader-real-corpus.yml`、
`docs/READER-REAL-CORPUS.md`、`docs/validation/reader-real-corpus.json`。
语料下载/生成/解析只在云端；仓库保存清单、许可记录、固定预期和消费者源码。

## 交付契约

- 覆盖EPUB/TXT/PDF/HTML/FB2/DOCX/RTF/MOBI/CBZ，目标每格式至少2份真实独立文件。
  每份登记固定URL/来源、作者、许可/公共领域依据、精确字节和SHA-256。
  仅使用有权再分发的公开材料；缺合法输入时明确pending，不用自动生成文件冒充真实文档。
  生成边界夹具可单列，不能增加真实语料计数，也不把本包结果直接改成旧1710计划完成。
- 按固定清单下载，散列或许可不符即停止该项，不自动换URL/样本或接受新版内容。
  输入和输出放云端工件，不使用用户文件、账号、会话或密钥。
- 用安装后冻结SDK：导入、公开原件回读、初页/末页/中间页、顺序翻页、返回/重开、
  文本查找与真实锚点capture/resolve、公开目录和metadata；按格式实际支持项逐项列出。
  固定页/重排/有界EPUB分开计量，零文本/零目录是可说明的文档属性，不能伪造检查通过。
- 可使用成熟引擎作交叉参考来定位差异，但不以“超越MuPDF”为目标、不接入其生产渲染。
  版面/像素差异分级记录；未定硬预算前只报告实际时间、峰值内存与输入规模。
- Windows/Linux在同一源码上实际运行，保存逐文件、逐操作状态及程序身份。
  不因一份坏文档中断所有证据采集，但最终汇总拒绝失败/跳过/缺项的完整通过声明。
  真正未支持的能力单列，不能通过删除样本、放宽预期或拼旧源码消除失败。
- 发现SDK问题只提交最小复现的公开输入身份、现象和建议，保持冻结源码不动，
  不粘贴崩溃栈或攻击细节；由root决定后续修复/重冻结。

## 云端出口

独立消费者和严格汇总：固定输入清单、来源/许可、下载散列、实际逐项执行、
同source/run/attempt/工件身份可核对。报告真实文件总数及九格式分别已验收/失败/pending数。
不能把格式smoke、合成样本或参考引擎成功算成EXReader真实语料通过。
