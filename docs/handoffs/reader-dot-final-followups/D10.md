完整目标与验收：

1. 修本包新驱动中的stale AX element：每次导航后重新查当前窗口/元素；回到书架后不再次等待已消失的reader.back。
2. 复用既有原生测试对UIKit Menu的已记录操作方法；功能可点击、AX isHittable原值、AX语义必须分列，不通过坐标点击把false改成true。
3. 大字体离屏控件先记录真实树/可见区域；只有实际可滚动容器才滚动，不对离屏元素直接请求activation point后丢弃失败。
4. 三目标各覆盖默认书架、阅读、More/低频操作、记录与设置，普通与大字体、light/dark分列；保存实际窗口树与原截图。
5. 采用原已验证的模拟器就绪准备，原动作/断言/等待预算不放宽。失败捕获不得因二次截图或元素读取异常覆盖主错误。
6. 负例覆盖stale节点、非本窗节点、缺一个移动目标、只有坐标点击无AX证据、缺配置或错误程序。严格认证本轮三个目标原ZIP与实际app程序。
