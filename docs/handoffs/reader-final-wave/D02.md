## 实际验收

1. 先列已有检查覆盖，再复用可调用的UIA/按键/截图工具；新增只填compact缺口。保留旧具名断言，不伪造旧守卫的分支/源码环境，不把旧报告当新执行。
2. Actions Windows实际宿主中，分别审查默认OFF与明确ON候选。记录实际DPI awareness、系统/窗口缩放和可用工作区；尝试100%、150%、200%，必须读回实际值。无法改变DPI的环境记pending，不用修改窗口大小冒充DPI。
3. 书架/阅读默认页、More菜单、展开完整面板、系统选择器、搜索、目录、记录、设置和账号入口，验证可见名称/角色/状态、Tab/Shift+Tab、Enter/Space/Escape、已有快捷键、关闭后焦点返回；步骤必须经过真实控件/键盘，不能直接调用业务回调代替。
4. 在基准及小窗口下记录可点击边界、文字截断、重叠、焦点可见性、屏外控件与菜单可达性。既有四格式流程复用原夹具；UI读不到的功能作为发现，不能生成假控件。
5. 正常与系统高对比设置审查实际文字/背景/焦点/禁用态；保存原始BMP/PNG及实际颜色来源。若计算对比度，注明WCAG算法、采样区域和抗锯齿局限，不能凭截图或主题名宣称全界面合规。
6. 无鼠标走一次导入→打开→翻页→搜索/目录→记录→返回；保留逐步UIA树/焦点/按键/截图。NVDA、Narrator、真人读屏未执行均保持未验证。
