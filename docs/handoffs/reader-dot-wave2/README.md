# Dot第二批共同约束

目标仍是原生、模块化、简洁UI的六目标阅读器。本批新增常用阅读能力与一个新SDK迁移验证出口；实现不能只交数据结构、空主函数或设计说明。复用现有静态组件、安装后的公开API和系统原生能力，不引入WebView、重复书籍解析器、动态插件框架或长期服务器。

## 固定起点与所有权

所有包从共同宿主候选 **a826a65c9c66e43620eff61b49cb79f941a3c953** 新建自己的指定分支与独立worktree/clone。这个起点包含Apple最终选择面板修复和GTK已交回文件入口，但不代表共同产品已验收。不要跟随移动主线、reset已有树或修改别人的工作树。本目录文档不一定在实现起点内，使用收到的固定URL阅读。

D01另允许只读构建明确列出的新SDK和模块版本选择源码；其它包只消费原冻结SDK3.40，不跟随新候选。D包没有互相等待或互相修改的关系。

## 不变项

- SDK固定 **9854061be331fe603a1822d9b2b36ee357154927**、3.40.0/ABI1。保护树src/include/cmake、顶层CMakeLists.txt、tests/fixtures、bindings及原native/reliability工作流逐字不改。D01也不能改这些文件；只在Actions的独立目录构建两个固定版本。
- 产品schema、wire v1、reading anchor v1/v2和既有parser/source身份规则不改；无新同步实体、第二套SDK库或私有SQL。用户字体、窗口策略是本机能力，不宣称跨设备同步。明确的小型本机私有记录可独立版本化，不能冒充产品事务。
- **所有构建、测试、语法检查（包括ast.parse/py_compile）、夹具/种子、服务、benchmark、工件下载/解包/解析仅在GitHub Actions。** 本地仅源码/文档/Git和只读GitHub运行元数据/日志。不能先本地检查再披露。
- 不用真实账号秘密、用户文档或真实云盘。测试素材、秘密、字体和平台fixture只在Actions临时环境生成或从固定许可来源取得。没有硬件/权限/可用服务就记录UNAVAILABLE/pending，不以stub代替实际能力授予。
- 可push本包功能分支并自行迭代Actions；不推默认、不合PR、不改保护规则、不签名发布、不创建tag/Release、不向外部发送消息。不得更改其它包、现有宿主/测试/工作流或中央任务说明。需要共享接口时给root具体公开签名和最小缺口。
- 保留所有原失败和原断言，不放宽数值/CPU/内存预算，不换掉失败语料，不把未运行写成通过。先阅读真实头文件/调用者，再定最小可用契约，不按目录名猜接口。

## 每包真实出口

独立可安装包和公开头/调用范例；C/C++模块提供C ABI，平台模块用原生组件和独立app/probe。写清所有权、线程、回调重入、取消、释放、提交边界、硬限额和失败输出，所有异常不得穿越C ABI。

每作业要求HEAD==GITHUB_SHA、固定起点祖先、冻结SDK/产品schema相等及路径白名单；新包不混入reading默认配置。安装后从新目录编译C/C++消费者（平台模块实际编译并运行原生probe），不靠源码相对include和私有实现。

具名正反例先于实现输出固定；覆盖正常操作、输入边界/坏Unicode、失败原子性、取消重试、错线程/重入、真实重开/终止恢复等适用场景。严格汇总核同source/run/attempt的完成作业和原始报告，认证工件唯一名称/ID/非空字节/API digest/有效期，在Actions下载重算ZIP摘要并拒绝重复/缺项/错源码/错attempt，绑定实际二进制/APK/原始结果。

交回完整受测SHA、最终HEAD及差异、分支、run/attempt/job、具名结果、工件身份和程序散列、原失败及限制。证据文档提交用[skip ci]，只按真实平台和范围授予。root负责后续宿主接线、共同源码复验与五轮集成审计；Dot不要自行增加下一批包。
