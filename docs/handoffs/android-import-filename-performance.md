# Android import filename coordination

The Android shelf's existing ten-case UI test and host review expect the selected filename, including its extension, in the import status and catalog title. A real DocumentsUI selection of `NewReview.txt` in Actions run 40628057571 instead displayed `Imported NewReview`; the status assertion failed before the subsequent filename search. The provider supplies `DISPLAY_NAME`; `ImportEntry.titleFrom` deliberately removes its extension, and the host was using that title hint for both status and import. The old import-entry contract and its existing probe require the extension-free default.

The candidate changes `ImportController` to opt into `ImportEntry.createWithDisplayFilename`. This new entry mode sanitizes the supplied display name with the same 256-byte UTF-8, no-control, no-separator rules and retains its extension and spelling. Other `create` callers retain the original extension-free title behavior. The selected string is persisted in the existing title sidecar, so newly staged requests keep that hint across recovery; already-staged sidecars keep their existing hint and are not rewritten. File identity and staging paths still derive from content and format, not provider names. A missing display name remains empty and a filename without an extension does not acquire an invented extension. The SDK's source bytes and budgets are unchanged.

This changes a user-visible Android host import title and therefore needs Android host-owner review when integrating with other Android work. In particular, review duplicate-content behavior, existing staged requests from before the change, displayed title/search expectations and recovery behavior on the final composition. No original import-entry, host, or shelf assertion was removed or weakened. The performance run exercises one new TXT selection; it does not replace the full original import-entry and host lifecycle suites, or grant their acceptance. Full-product, delivery-package, physical-device and performance-budget acceptance remain separate.
