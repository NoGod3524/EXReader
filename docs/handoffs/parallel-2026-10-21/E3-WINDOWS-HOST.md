# E3：WP13 Windows 原生宿主闭环

你负责把现有Windows参考宿主补成可独立验收的导入/书架/阅读/选文/标注/恢复闭环。先读同目录`README.md`；在既有Win32实现上增量完成，不重新造阅读引擎或换大型UI框架。

## 起点

- 分支`codex/wp13-windows`，实现基线`a2552d7feb786cd2345d2b0b3eb894777b3254db`。
- 现有源为`examples/reader.c`；通过已安装SDK构建，`tools/build_windows_host.py`打包并验证，原Windows自检26项需保留。
- 现有进度使用宿主设置文件，不能把它当作已实现SQLite书架/标注。首先核对实际行为，再按本包范围补齐。

## 必做功能

1. 非阻塞导入与书架，使用当前SDK支持范围和公开书库接口；元数据、去重、删除/打开、错误提示有真实数据通路。
2. 重排和固定页阅读保持既有能力，支持上一页/下一页、字号或缩放、窗口调整；未支持或超限输入明确显示，不静默丢页。
3. 用户可选择文字、复制引用、添加/编辑/删除标注、从标注列表回到原位置。重排位置和PDF/CBZ固定页位置分别处理。
4. 书架、进度与标注持久化，关闭进程后重开恢复；字号/窗口改变后使用锚点重定位，歧义位置明确提示。
5. 导入/翻页任务串行拥有SDK句柄，关闭窗口和取消时正确回收；UI线程不等待整本解析，旧任务不得覆盖新书画面。
6. 键盘焦点、可访问名称、控件标识与逻辑顺序稳定，供后续WP14接入；不把本包宣称为完整屏幕阅读器验收。

## 文件所有权

拥有`examples/reader.c`、新增`examples/windows/**`、`tools/build_windows_host.py`、新增`tools/check_windows_host.py`、`tests/windows_host/**`、`.github/workflows/wp13-windows.yml`、`docs/WP13-WINDOWS.md`、`docs/validation/wp13-windows*.json`。

`examples/CMakeLists.txt`为集成人所有；如需要新源文件/链接项，提供最小集成补丁，或在`examples/windows/`中提供独立consumer构建。共享Swift/JNI、字体工具和其他平台只读。

公开API入口：`library.h`、`layout.h`、`document.h`、`pdf.h`、`canvas.h`；已有`examples/window.c`展示独立有界EPUB入口。不要直接改SQLite表、引擎内部或资源预算。

## 云端验收

- Windows hosted runner构建并运行真实应用，保留原26项自检。
- 新增至少20条可复现交互/生命周期步骤：导入、书架切换、前后翻页、字号/窗口变化、选文、标注增改删与导航、关闭重开、任务取消与错误恢复。必须记录实际自动操作或人工执行状态，内部函数自检不能代替整套UI步骤。
- 至少包含EPUB和PDF的已有路径；其余格式按公开SDK实际支持声明。大章能力是否使用有界入口单列，不把快照限制隐去。
