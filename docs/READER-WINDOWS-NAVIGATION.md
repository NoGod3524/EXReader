# Windows 原生目录导航候选

状态：实现与 Actions 验收出口已提交，尚无通过的云端结果，不授予验收。

基点 `3917897e`；SDK 仍为 `9854061be331fe603a1822d9b2b36ee357154927`、3.40.0 / ABI 1。原 F2、F1、阅读状态包、产品 schema 与 SDK 均不修改。

宿主使用安装后的 `EXReaderNavigation 0.1.0`，编译开关为 `EXR_READER_WINDOWS_NAVIGATION`，默认关闭，可在不启用 F1 搜索的情况下独立编译。主窗口提供“目录”次级按钮，Ctrl+G 打开原生目录窗口，Enter 定位，Escape 取消任务或关闭窗口。

作者目录保留原顺序、重复标签与层级。窗口每批保留最多 32 行，支持子目录、上一级与前后批。PDF/CBZ 明确标为“按页入口（不是作者目录）”，不宣称 PDF 作者大纲支持。文本作为纯原生控件文字显示。

每个后台任务在同一 OS 线程内创建、查询、解析和释放 F2 快照，不把线程绑定句柄存到下一任务。窗口仅保留自有行副本与数值选择。原件身份由公开侧载适配器验证的格式、SHA-256、字节数和解析版本组成，与当前绘制文档打开时身份核对。

定位先在一个独立 SDK 原件上调用 F2，再用第二个独立 SDK 原件的原始公开接口核对章节、片段节点、CFI 或稳定页 ID。重排目标创建真实锚点后在当前绘制文档上解析；有界 EPUB 额外逐块核对当前 pager 与独立章节的完整规范化文本投影。固定页在当前绘制文档中再次核对稳定页 ID，然后走既有绘制和进度接受路径。

重复 spine 必须明确选择具体书内顺序；片段缺失时仅提供明确的“打开章节起点”操作；外链不自动启动；身份变化、无法证明的 CFI、取消和失败保留阅读位置。目录列表不写笔记、产品修订或 outbox。实际成功定位沿用宿主原有阅读进度保存。

工作流 `.github/workflows/reader-windows-navigation-ui.yml` 运行原安装后 F1/F2 消费者、新目录窗口检查，以及原 Windows 搜索、158 步 UI、账号、书架、元数据、键盘与 UI Automation 回归。严格汇总核对同轮源码、作业、工件 ZIP 摘要、完整具名检查和实际程序哈希。新增故障观察仅编入隔离的 Review 程序，分发程序不编入。

本候选尚未构建；全部编译、语法检查、夹具生成、运行和工件解析仅在 GitHub Actions。真机读屏、性能预算和六平台共同源码验收未授予。
