## 已实现接线

- 账号选择、HTTPS WebDAV 地址、用户名及安全密码输入、钥匙串授权更新。
  `accounts.json` 仅保存独立小写 UUID、根地址与匿名访问标记。
  账号各有独立 SDK 库、产品库、原件目录及阅读/书架偏好。
  账号记录最多 16 个、编码文件最多 64 KiB；写前检查大小。原文件无法读取时，
  创建和凭据更新均拒绝，保留原文件及既有钥匙串，等待用户恢复。
- 使用已安装 Credentials。钥匙串拒绝时保留本次授权，并显示实际保存结果；
  明确选择临时授权时尝试移除旧钥匙串记录，失败会显示具体状态。
  匿名模式在重启后保持，根地址禁止用户信息、查询和非 HTTPS。
- 每个账号在本进程的窗口共享一个实际 Session 控制器。准备、运行和关闭互斥；
  切换账号、更新授权、视图离开及非活跃场景会取消准备并请求非阻塞关闭。
  只有观察到 CLOSED 后才能 destroy，不在主线程 join；终态停止本地快照计时器。
- 按稳定书籍 key 每批至多 50 条准备本机原件。SDK owner 以 64 KiB 缓冲读取
  公开 source，核对完整摘要及字节，写入私有不可变副本后释放借用。
  既有副本也复核；目录和已有目标拒绝符号链接。
- 对已验证的旧本机书显式 bootstrap typed book 命令，保留产品标题、作者和收藏，
  不重复创建历史或 outbox。每个同步 owner 任务内打开、使用并关闭修订句柄，
  避免 DispatchQueue 任务换线程时跨线程复用 native 句柄。
- 所有网络只接收产品路径、复制后的授权及已验证原件，不接收 SDK 句柄。
  每次手动请求只执行一轮 256 分片扫描，随后变更需再次同步。

## 安装与链接

`tools/build_apple_product.py` 将正常产品包安装到已有冻结 Apple SDK 旁。
宿主编译器通过 `tools/apple_swift.py` 与相同的 Xcode 配置使用其已安装头和归档。
`CReaderSQLite` Swift 模块明确指向该产品头，链接仅使用 `libreader_catalog_sqlite.a`；
阅读状态只链接 codec，解析继续由已有动态 SDK 完成。

每份实际程序都生成链接图并检查 SQLite 的唯一符号/对象来源，拒绝系统 SQLite、
第二份静态 SDK 及完整静态 reading resolver，并核对实际 SQLite 符号归属的对象。
另有七种证据改写拒绝检查。Xcode 与正式宿主均先链接产品归档，再链接动态 SDK，
不允许 SDK 导出符号代替产品 provider。保留原始 nm 输出和链接图。
原 WP13、导入映射和书架套件保留，不能以账号检查替换。
