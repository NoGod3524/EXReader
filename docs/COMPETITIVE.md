# 参考引擎与性能度量

2026-10-22 起，目标收敛为：保留多格式解析与自有 PDF 渲染核心，优先提供轻量、可靠、高性能的阅读 SDK。
原“全面领先 MuPDF、CREngine、Readium、foliate-js”目标撤销。实现范围按真实阅读需求和资源成本选择，
成熟引擎提供质量与性能参照。

本文件定义度量口径并保留历史基线。新优化以固定源码、构建、设备和同一语料的可复现数据验收。

## 参考对象与用途

| 参考对象 | 对照用途 | 当前工具 |
| --- | --- | --- |
| MuPDF | PDF 打开/绘制正确性、文字与几何、像素差异，以及同质量下的延迟/内存 | `tools/compare_reference.py` 有像素对照；统一性能对照待建 |
| CREngine | 同书、同字体/页宽下的可读性、断词、表格及分页异常 | 按缺陷需要建立最小对照 |
| Readium | 宿主接口、稳定定位及阅读交互设计参考 | 按接入需要评估 |
| foliate-js | EPUB 常见 HTML/CSS 的显示与交互参考 | 按缺陷需要建立最小对照 |

## 轻量与性能出口

分别记录纯核心、多格式阅读核心（含 PDF）和所选扩展组合；编译器、优化开关、静态/动态链接、
符号剥离与依赖文件必须登记。字体、模型、测试资源与程序分别计量，报告组合运行依赖总大小。

| 指标 | 计量范围 |
| --- | --- |
| 体积与依赖 | 发布库与必要运行依赖的字节数；关闭可选组件后的依赖检查 |
| 打开与首屏 | 分列索引/解析、首次可显示页面的端到端耗时；冷/热缓存分开 |
| 翻页与跳页 | 连续翻页和固定随机计划的 p50/p95；缓存未命中与恢复另列 |
| 内存 | 独立进程峰值 RSS，以及源文件/映射、解析工作区、页缓存和显式快照载荷 |
| 正确性与限界 | 正文/页面定位、代表页差分、超限/取消/畸形输入可控退出 |

先对真实使用场景的代表性固定语料建立基线，再登记各 profile 的绝对预算和回归容差。
预算尚待实测冻结。每次核心变更运行相关快速回归；长测、完整语料与跨平台矩阵在对应风险变化或发布候选时执行。
不同系统、CPU、渲染质量、字体、线程和缓存条件分别报告，不能据此合并排名。
像素差异用于定位原因，字体栅格差异须分类；任何速度收益都须同时报告正确性和内存变化。

## MuPDF 对照口径

`python tools/compare_reference.py <libexreader.dll> <目录> [--scale 1] [--json out]`

- 两侧都渲染第 1 页，同尺寸（scale=1 即 1 点 = 1 像素）；
- 输出每文件的 `mean_abs`（RGB 平均绝对差）、`max_abs`、`percent_differing`（单通道差 >8 的像素占比）；
- 打开或渲染失败记 `exreader-format` / `exreader-unsupported` / `size-mismatch` 等原因；
- **已知应失败**的故意损坏夹具（`*-bad-*`、`group-malformed`）在统计时单独计，不算作兼容失败。

语料：`tests/fixtures/pdf-blend`（42 个文件，其中 16 个是故意的畸形样本）。

**在跑真实语料之前，不得引用本表宣称领先或落后。**

## 公开语料基线（2026-10-18）

语料由 `tools/fetch_corpus.py` 下载，逐文件记录 URL、许可与 SHA-256，`tests/corpus/` 不入库。

| 语料 | 文件数 | 可比对 | 拒绝（format/unsupported） | 参考失败 | 平均 RGB 绝对差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| qpdf 测试套件（Apache-2.0，含大量故意损坏样本） | 60 | 23 | 30 | 7 | 0.401 |

**这不是“落后 60%”的结论**：两套语料都包含大量专门的解析器压力样本（坏 xref、坏 ToUnicode、
故意截断）。它说明的是**解析严格度**：MuPDF 有修复模式，我们没有。真实书籍语料的比率待测。

### 当时的候选修复顺序（历史）

以下来自 2026-10-18 分类；新排期须核对当前源码、真实影响及资源预算。

1. **xref 修复**：表/流损坏时按对象扫描重建，取代直接拒绝；
2. **ToUnicode 容错**：codespace 缺失或重叠时退回逐字节映射，而不是整页拒绝；
3. **非 RGB 透明组色空间**（CMYK/Gray 组）；
4. 注释外观标志（NoZoom/NoRotate）；
5. 对象流 `Extends`。
