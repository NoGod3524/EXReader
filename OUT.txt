D1 is finished. The engine now renders fixed-layout EPUB pages as fixed pages instead of treating them as reflowable text. Eight books cover all six book types, every item passes on every book where it applies, the 19 reflowable books are unchanged, and draft **PR #120** is open: https://github.com/NoGod3524/EXReader/pull/120

**What changed:** fixed-layout pages used to be reflowed (Haruko had 14 pages at one size and 15 at another). Now each fixed page is laid out once at its own declared size and scaled evenly to fit the screen, centred, never stretched or cropped. It is always exactly one page. The page size comes from, in order:
1. the page's own `<meta name="viewport">`
2. the book-level `rendition:viewport`
3. the size of the page's first image
4. the screen size

Absolute positioning (`position:absolute` with top/right/bottom/left) is applied on fixed pages only. I added four public functions; no existing function signatures changed.

## Limits and changes to existing items
- **Not supported:** CSS `transform` (the magazine's `rotate(-8deg)` caption renders unrotated), `z-index`, and SVG pages in the reading order. Opening a whole EPUB with `exr_document_open` still lays everything out as reflow; fixed layout applies on the per-part publication path the reader uses.
